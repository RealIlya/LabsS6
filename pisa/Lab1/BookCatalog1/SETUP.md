# BookCatalog — инструкция по сборке и запуску

Проект представляет собой ASP.NET Web Application на C# / .NET Framework 4.7.2 с хранением данных в памяти (без базы данных). Запуск осуществляется через IIS Express, который входит в состав Visual Studio.

---

## Требования

Перед началом убедитесь, что на устройстве установлено следующее:

| Компонент | Версия |
|---|---|
| Windows | 10 / 11 или Windows Server 2016+ |
| Visual Studio | 2019 или 2022 (Community, Professional или Enterprise) |
| Workload в VS Installer | **ASP.NET and web development** |
| .NET Framework Developer Pack | **4.7.2** |
| IIS Express | устанавливается автоматически вместе с Visual Studio |

> Если вы не уверены, установлен ли нужный workload — откройте **Visual Studio Installer**, найдите свою версию VS, нажмите **Modify** и проверьте наличие галочки у «ASP.NET and web development».

---

## Шаг 1 — Клонирование репозитория

Откройте терминал и выполните:

```bash
git clone <url-репозитория>
```

Разместите папку по пути **без кириллицы и пробелов**, например:

```
C:\Projects\BookCatalog
```

Пути вида `C:\Мои проекты\Книжный каталог` могут вызвать ошибки сборки в IIS Express.

---

## Шаг 2 — Открытие проекта в Visual Studio

Откройте файл решения одним из способов:

- двойной клик на `BookCatalog.sln` в проводнике, или
- Visual Studio → **File → Open → Project/Solution** → выбрать `BookCatalog.sln`.

---

## Шаг 3 — Восстановление NuGet-пакетов

В панели **Solution Explorer** кликните правой кнопкой на названии решения (верхний узел) и выберите **Restore NuGet Packages**. Дождитесь завершения — статус отображается в нижней строке окна.

---

## Шаг 4 — Проверка целевой платформы

В **Solution Explorer** кликните правой кнопкой на проекте **BookCatalog** → **Properties** → вкладка **Application**.

Убедитесь, что в поле **Target framework** выбрано **\>= .NET Framework 4.7.2**.

Если значение отличается — смените его на 4.7.2 и сохраните (`Ctrl+S`). Visual Studio может попросить перезагрузить проект — согласитесь.

---

## Шаг 5 — Сборка и запуск

Нажмите **F5** (или кнопку **IIS Express** на панели инструментов).

Visual Studio соберёт проект и автоматически откроет браузер по адресу вида:

```
http://localhost:ПОРТ/
```

Номер порта назначается автоматически и может отличаться на каждом устройстве.

---

## Тестовые учётные записи

После запуска доступны два предустановленных аккаунта:

| Роль | Email | Пароль |
|---|---|---|
| Администратор | admin@test.com | admin123 |
| Читатель | user@test.com | user123 |

> **Важно:** все данные хранятся в оперативной памяти. При каждом перезапуске IIS Express состояние сбрасывается до начального — добавленные книги, пользователи и брони не сохраняются между сессиями.

## Частые проблемы

**Ошибка «Could not find type or namespace»**

Убедитесь, что шаг «Restore NuGet Packages» выполнен успешно. Если ошибка сохраняется — попробуйте **Build → Clean Solution**, затем снова **Build → Build Solution**.

**Браузер не открывается или порт занят**

Зайдите в свойства проекта (**Properties → Web**) и нажмите **Create Virtual Directory** или смените номер порта вручную.

**Ошибка «The target framework is not installed»**

Скачайте и установите [.NET Framework 4.7.2 Developer Pack](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net472) с сайта Microsoft, после чего перезапустите Visual Studio.

**Проект открывается, но страницы не грузятся**

Проверьте, что IIS Express запущен — его иконка должна отображаться в системном трее Windows. Если иконки нет — запустите проект заново через F5.
