# Лабораторная работа №3 — Краткое описание

## Что было сделано

В приложение «Книжный каталог» (ASP.NET WebForms, C#, SQL Server) добавлена технология AJAX для обновления данных без перезагрузки страниц и асинхронной валидации ввода.

## Основные изменения

### 1. AJAX-валидация ввода

- **Проверка ISBN** (AddBook.aspx) — при вводе ISBN автоматически проверяется уникальность через jQuery AJAX + Generic Handler (.ashx). Debounce 300мс, визуальная индикация ✓/✗.
- **Проверка email** (Register.aspx) — при регистрации email проверяется на занятость через PageMethods. Debounce 500мс.
- **Валидаторы** — на 6 страницах установлены ASP.NET валидаторы: RequiredField, RegularExpression, Range, Compare. Всего 35+ валидаторов.
- **Динамическая валидация** (WriteOff.aspx) — RangeValidator обновляет максимум при выборе книги (TotalCount), сообщение об ошибке показывает реальное количество.

### 2. Обновление данных без перезагрузки

- **Поиск книг** (Default.aspx) — UpdatePanel, результаты обновляются асинхронно, состояние поиска сохраняется в Session.
- **Добавление книги** (AddBook.aspx) — UpdatePanel, проверка ISBN до отправки формы.
- **Регистрация** (Register.aspx) — UpdatePanel, проверка email в реальном времени.
- **Авторизация** (Login.aspx) — UpdatePanel, детектор Caps Lock.
- **Бронирование** (Booking.aspx) — UpdatePanel, статус обновляется мгновенно.
- **Списание книг** (WriteOff.aspx) — UpdatePanel с двухшаговым flow: выбор книги → подтверждение с причиной и количеством. Поддержка отмены броней перед списанием. Позиция скролла сохраняется через sessionStorage.

### 3. Интерфейс

- Переработана страница списания: вместо полей сверху — панель подтверждения при клике на [СПИСАТЬ].
- Таблица книг на главной: кнопка [ЗАБРОНИРОВАТЬ] на отдельной строке под [ПОДРОБНЕЕ], колонки на процентах с переносом слов.
- Рекламные слоты с интерактивной слот-машиной (vanilla JS).

## Технологии

- ASP.NET WebForms (.NET Framework 4.x)
- C# (code-behind)
- SQL Server (ADO.NET, параметризованные запросы)
- jQuery 3.7.0 (AJAX-проверка ISBN)
- Vanilla JavaScript (слот-машина, сохранение скролла)
- CSS (тема NieR: Automata Light/Ruins Edition)
