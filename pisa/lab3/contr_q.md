## Контрольные вопросы

### 1. Что такое технология AJAX?
AJAX (Asynchronous JavaScript and XML) — это подход к разработке веб-приложений,
при котором часть данных загружается и обрабатывается асинхронно, без полной
перезагрузки страницы. Основан на объекте XMLHttpRequest для фоновых HTTP-запросов
и DOM-manipulation для динамического обновления интерфейса.

### 2. Какая роль отводится языку JavaScript в технологии AJAX?
JavaScript — основной клиентский компонент AJAX. Он:
- Создаёт и отправляет XMLHttpRequest
- Обрабатывает ответы сервера
- Динамически обновляет DOM-дерево страницы
- Обеспечивает валидацию данных на стороне клиента
- Управляет событиями (ввод текста, нажатие кнопок)

### 3. Какую роль играет XML в технологии AJAX?
Исторически данные передавались в формате XML (отсюда название). В современных
приложениях чаще используется JSON как более компактный и удобный для JavaScript
формат. В данном проекте используется JSON.

### 4. В каких случаях целесообразно использовать AJAX?
- Поиск/фильтрация данных в реальном времени
- Валидация полей формы на сервере (проверка email, ISBN)
- Редактирование данных без перезагрузки
- Подгрузка контента (бесконечная прокрутка)
- Интерактивные формы (бронирование, корзина)

### 5. Какие преимущества дает AJAX?
- Повышение удобства использования (нет перезагрузок)
- Снижение нагрузки на сервер (обновляются только части страницы)
- Более быстрый отклик интерфейса
- Снижение трафика

### 6. Какими недостатками обладает AJAX?
- Сложность отладки (асинхронный код)
- Проблемы с историей браузера (нужно управлять URL)
- SEO-проблемы (контент генерируется динамически)
- Зависимость от JavaScript (без него приложение не работает)

### 7. Каким образом можно использовать AJAX в ASP.NET?
- **UpdatePanel** — декларативный подход, минимальный код
- **PageMethods** — вызов статических [WebMethod] из JavaScript
- **Web API / Handlers** — RESTful endpoints + jQuery/JS fetch
- **SignalR** — для real-time двустороннего обмена

### 8. Какие элементы управления сервера существуют в ASP.NET AJAX?
- **ScriptManager** — управляет AJAX-скриптами и частичным отображением
- **UpdatePanel** — обеспечивает частичное обновление страниц
- **UpdateProgress** — отображает индикатор загрузки
- **Timer** — запускает периодические обратные вызовы
