# Ответы на контрольные вопросы к лабораторной работе №3

## 1. Что такое технология AJAX?

AJAX (Asynchronous JavaScript and XML) - это подход к построению веб-интерфейсов, при котором браузер обменивается данными с сервером асинхронно, без полной перезагрузки страницы. Пользователь продолжает работать с текущей страницей, а обновляется только нужная часть интерфейса или выполняется фоновая проверка данных.

В данной лабораторной работе AJAX используется для поиска книг без полной перезагрузки страницы, проверки ISBN, проверки email, бронирования и списания книг через частичное обновление интерфейса.

## 2. Какая роль отводится языку JavaScript в технологии AJAX?

JavaScript выполняет клиентскую часть AJAX-взаимодействия. Он реагирует на действия пользователя, отправляет асинхронные запросы к серверу, получает ответ и обновляет элементы страницы через DOM.

Также JavaScript используется для предварительной проверки данных, показа индикаторов загрузки, debounce-задержек при вводе и вывода сообщений о результате проверки. При этом JavaScript не должен быть единственным местом проверки правил: важные ограничения должны повторно проверяться на сервере.

## 3. Какую роль играет XML в технологии AJAX?

XML исторически был одним из основных форматов передачи данных в AJAX, что отражено в названии технологии. С помощью XML сервер мог возвращать структурированные данные, которые затем обрабатывались JavaScript.

В современных веб-приложениях XML часто заменяется JSON, потому что JSON компактнее и естественнее обрабатывается в JavaScript. Смысл AJAX от этого не меняется: браузер асинхронно получает структурированный ответ от сервера и обновляет интерфейс без полной перезагрузки страницы.

## 4. В каких случаях целесообразно использовать технологию AJAX?

AJAX целесообразно использовать там, где действие пользователя требует ответа сервера, но не требует перерисовки всей страницы. Это улучшает отзывчивость интерфейса и уменьшает визуальные сбросы.

Типичные случаи:

- проверка уникальности email, ISBN или другого значения;
- поиск и фильтрация данных;
- обновление статуса операции;
- отправка формы с показом результата на той же странице;
- частичное обновление таблицы, панели или блока данных.

В лабораторной работе это проявляется в проверке ISBN и email, поиске книг, бронировании и списании без полной перезагрузки страницы.

## 5. Какие преимущества дает технология AJAX по сравнению с обычным веб-интерфейсом?

AJAX повышает отзывчивость интерфейса: пользователь быстрее получает обратную связь и не ждёт полной перезагрузки страницы после каждого действия.

Основные преимущества:

- обновляется только нужная часть страницы;
- уменьшается количество полных перезагрузок;
- формы становятся удобнее за счёт ранней проверки ошибок;
- интерфейс выглядит более плавным;
- можно выполнять фоновые проверки до отправки всей формы.

Например, проверка ISBN до сохранения книги позволяет сразу сообщить пользователю, что книга с таким ISBN уже существует.

## 6. Какими недостатками обладает AJAX?

Главный недостаток AJAX - рост сложности приложения. Асинхронные запросы сложнее отлаживать, нужно учитывать задержки сети, ошибки сервера, повторные клики и устаревшие ответы.

Также AJAX может привести к смешению ответственности: часть логики оказывается в JavaScript, часть - на сервере, часть - в элементах Web Forms. Поэтому важно понимать, где принимается окончательное решение.

Критические проверки нельзя переносить только в браузер. Клиентская проверка улучшает удобство, но серверная проверка остаётся обязательной, потому что клиентский код можно обойти.

## 7. Каким образом можно использовать AJAX в ASP.NET?

В ASP.NET Web Forms AJAX можно использовать несколькими способами.

Первый способ - через компоненты ASP.NET AJAX: `ScriptManager`, `UpdatePanel`, `UpdateProgress`, `Timer`. Этот подход удобен, когда нужно сохранить серверную событийную модель Web Forms и обновлять только часть страницы.

Второй способ - через JavaScript-запросы к серверным методам или обработчикам. Например, можно вызвать `PageMethods` или отдельный `.ashx`-обработчик и получить короткий ответ в формате JSON.

В данной лабораторной работе используются оба подхода: `UpdatePanel` для частичного обновления страниц и jQuery AJAX/обработчик для проверки ISBN.

## 8. Какие элементы управления сервера существуют в ASP.NET AJAX?

К основным серверным элементам ASP.NET AJAX относятся `ScriptManager`, `UpdatePanel`, `UpdateProgress` и `Timer`.

`ScriptManager` подключает и координирует AJAX-инфраструктуру на странице. Без него компоненты ASP.NET AJAX не работают корректно.

`UpdatePanel` позволяет обновлять часть страницы без полной перезагрузки. Он особенно полезен в Web Forms, потому что сохраняет привычную модель серверных событий.

`UpdateProgress` показывает пользователю, что выполняется асинхронная операция. Это важно для обратной связи, чтобы пользователь не нажимал кнопки повторно из-за отсутствия реакции.

`Timer` позволяет запускать периодические обновления по интервалу. Его можно использовать вместе с `UpdatePanel`, если данные должны обновляться автоматически.
