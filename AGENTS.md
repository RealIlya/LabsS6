# Repository Guidelines

## Working Language

- Рабочий язык взаимодействия: русский.
- Отчёты и сопроводительные материалы оформляются на русском (английский допустим для кода, команд и терминов фреймворков).

## Reporting Format Priority

- Приоритетный формат исходника отчёта: `*.tex` на движке **XeLaTeX**.
- Цель: максимально предсказуемая типографика и форматирование, близкое к итоговому `docx`.
- Допустимый альтернативный формат: обычный `*.docx` (Word), если это требуется преподавателем или регламентом дисциплины.

## Reporting Rules

- В основной отчёт включать только требуемые разделы по методичке.
- Поля страницы по умолчанию: левое `3 см`, верхнее `2 см`, нижнее `2 см`, правое `1.5 см`.
- Абзацный отступ первой строки: `1 см`.
- Выравнивание основного текста: по ширине.

## Title Page And PDF Build

- Правила этого раздела активируются по команде пользователя: `сделай полный отчёт`.
- В папке `$title-folder` хранится исходник титульного листа для каждой лабы в формате `html+css`.
- Все плейсхолдеры в титульнике и связанных шаблонах отчёта заменять данными из материалов и методичек именно текущей лабораторной работы.
- Для каждой лабораторной в титульнике обязательно задавать корректные: заголовок работы, номер лабы и название дисциплины.
- В каждой папке предмета должен быть файл `tutors-list.txt` с фамилиями преподавателей для отчёта.
- Если `tutors-list.txt` отсутствует, сообщить об этом пользователю и остановить сборку отчёта.
- Для каждой лабы сначала собирать `title.pdf` из исходника титульника.
- После подтверждения пользователя, что титульник и отчёт корректны, собирать итоговый `report.pdf`, который включает `title.pdf` и основной отчёт.
- Нумерация страниц в итоговом `report.pdf`: титульный лист без номера, на первой странице основного отчёта номер `1`.
- Сборку выполнять единым пайплайном с одним entrypoint (без генерации вспомогательных скриптов в папках конкретной лабы, например в `*/report/scripts`).

## Control Questions

- Если в файлах лабы есть контрольные вопросы, готовить ответы в отдельном `*.md` рядом с материалами этой лабы (например, `control-questions.md`).
- Стиль ответов: умеренно строгий (чёткие формулировки, по существу, без разговорных вставок).
- Приоритет источников: теория из лабораторной работы и методических материалов по дисциплине.
- Если данных в лабораторной/методичке недостаточно, дополнять ответы проверяемыми источниками из интернета.

## Table And Figure Captions

- Подпись таблицы: сверху справа, формат `Таблица N`, нумерация сквозная по всему документу.
- При переносе таблицы: сверху справа `Продолжение таблицы N`.
- Подпись рисунка: снизу по центру, формат `Рис. N`.
- Ссылки в тексте на рисунки: `на рис. N`.
