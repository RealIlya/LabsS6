# Repository Guidelines

## Working Language

- Рабочий язык взаимодействия: русский.
- Отчёты и сопроводительные материалы оформляются на русском (английский допустим для кода, команд и терминов фреймворков).

## Reporting Format Priority

- Приоритетный формат исходника отчёта: `*.tex` на движке **XeLaTeX**.
- Цель: максимально предсказуемая типографика и форматирование, близкое к итоговому `docx`.
- Допустимый альтернативный формат: обычный `*.docx` (Word), если это требуется преподавателем или регламентом дисциплины.

## Reporting Rules

- В отчёт включать только требуемые разделы по методичке; ответы на контрольные вопросы не добавлять, если преподаватель отдельно не запросил.
- Поля страницы по умолчанию: левое `3 см`, верхнее `2 см`, нижнее `2 см`, правое `1.5 см`.
- Абзацный отступ первой строки: `1 см`.
- Выравнивание основного текста: по ширине.

## Table And Figure Captions

- Подпись таблицы: сверху справа, формат `Таблица N`, нумерация сквозная по всему документу.
- При переносе таблицы: сверху справа `Продолжение таблицы N`.
- Подпись рисунка: снизу по центру, формат `Рис. N`.
- Ссылки в тексте на рисунки: `на рис. N`.
