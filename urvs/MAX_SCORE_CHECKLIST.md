# Чек-лист на максимум баллов (Лабы + РГР/РГЗ)

## Что взято за основу

- `Методические указания УпРес_2022.pdf`.
- `Правила_UR_2026_ПМИ.doc`.
- В документе правил встречаются оба обозначения: `РГР` и `РГЗ`; далее используется формулировка `РГР/РГЗ`.

## Балльная модель

- За семестр (лабы + РГР/РГЗ): максимум `60`, минимум `30`.
- Экзамен: максимум `40`.
- При результате за семестр `> 90` итог может быть выставлен «автоматом» как `95`.
- Для положительной оценки на экзамене нужно ответить минимум на половину вопросов.

## Обязательный минимум для допуска к экзамену

- Выполнить и защитить лабораторные `№1`, `№2`, `№3`.
- Выполнить РГР/РГЗ минимум на `I` уровне.
- Если минимум не выполнен, к экзамену не допускают.

## Как набрать максимум 60 за семестр

- Лабы: набрать максимум по четырём работам (баллы выше 4 работ не учитываются).
- Практический оптимум по таблице: `ЛР1 (9) + ЛР2 (10) + ЛР3 (10) + ЛР5 (15) = 44`.
- РГР/РГЗ: делать уровень `IV` (`16` баллов).
- Итого: `44 + 16 = 60`.

## Сроки и план по неделям

- ЛР1: недели `1–4`.
- ЛР2: недели `5–8`.
- ЛР3: недели `9–12`.
- ЛР4/ЛР5: недели `13–16`.
- РГР/РГЗ: вести параллельно с лабами, крайний срок — `15` учебная неделя.
- Опережение сроков приветствуется.

## Что обязательно для каждой лабораторной

- Реализовать вариант задания (в методичке: shell и/или C в зависимости от лабы).
- Отладить и протестировать программу до защиты.
- Учесть критерии оценивания:
  - корректность решения;
  - стиль кода;
  - корректная обработка ошибок;
  - проверка кодов завершения системных вызовов;
  - информативные ошибки в `stderr`;
  - корректные коды возврата программы;
  - достаточные комментарии;
  - полнота тестов (цель, ожидаемый результат, фактический результат);
  - соответствие графику;
  - качество отчёта;
  - ответы на контрольные вопросы.
- Лабораторная представляется преподавателю не более `2` раз.

## Этапы приёма лабораторной

1. Демонстрация работы программы на компьютере.
2. Объяснение отчёта и логики решения (теория + практика).
3. Защита: ответы на контрольные вопросы.

## Требования к отчёту по лабораторной

- В отчёте указать подробную спецификацию:
  - полный путь к каталогу на сервере;
  - как собрать и запустить;
  - какие параметры передавать.
- Отчёт должен подтверждать воспроизводимость запуска и проверки.

## Что обязательно по РГР/РГЗ

- Работа выполняется индивидуально.
- Программа должна соответствовать одному из уровней `I/II/III/IV`.
- Уровень `I` обязателен для всех; для максимума целиться в `IV`.
- Для проверки отправляется письмо преподавателю с комплектом файлов по требованиям методички РГР.
- Критерии оценивания РГР/РГЗ: корректность, понимание логики и теории, стиль, обработка ошибок, достаточность тестов, качество отчёта.

## Краткий предсдачный контроль

- [ ] Есть план на 60: 4 лабы с максимумом + РГР/РГЗ IV.
- [ ] Для каждой работы подготовлены тесты и лог ошибок через `stderr`.
- [ ] Отчёты содержат команды сборки/запуска и параметры.
- [ ] Подготовлены ответы на контрольные вопросы по каждой лабе.
