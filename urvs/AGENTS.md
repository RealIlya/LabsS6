# Repository Guidelines

## Project Structure & Module Organization
Репозиторий содержит материалы по курсу УРВС и артефакты лабораторных.
- Корень: `Методические указания УпРес_2022.pdf`, `Правила_UR_2026_ПМИ.doc`, `tutors-list.txt`, `AGENTS.md`.
- Решения размещайте по лабораторным: `lab1/`, `lab2/` и т.д.
- Внутри лабы разделяйте `shell/`, `c/`, `report/`, `tests/`, `control-questions.md`.
- Временный парсинг документов храните в `out/` и не коммитьте.

## Build, Test, and Development Commands
Единого `Makefile` нет; используйте команды.
- `rg --files` — обзор содержимого репозитория.
- `python C:/Users/Admin/.codex/skills/pdf-docx-parser/scripts/parse_document.py "Методические указания УпРес_2022.pdf" out/method` — извлечь требования из PDF/DOCX.
- `rg -n "Лабораторная работа|контрольные вопросы|должен" out/method/document.md` — найти обязательные пункты.
- `gcc lab1/c/main.c -Wall -Wextra -Werror -std=c11 -o build/lab1` — типовая сборка C-части.

## Coding Style & Naming Conventions
- Рабочий язык: русский; код, команды и идентификаторы допускаются на английском.
- C: один исходник, кроссплатформенность через `#ifdef _WIN32 ... #else ... #endif`, отступ 4 пробела, ошибки в `stderr`.
- Shell: POSIX `sh`, понятные имена переменных, явная обработка ошибок.
- Именование: каталоги `labN`, файлы `snake_case` (`report.tex`, `control_questions.md`).

## Testing Guidelines
- Для каждой лабы фиксируйте минимум 1 позитивный и 1 негативный тест.
- Добавляйте `tests/README.md`: команда, цель теста, ожидаемый и фактический результат.
- Перед защитой подтверждайте корректное завершение и обработку ошибочного ввода/файлов.

## Commit & Pull Request Guidelines
- Префиксы коммитов: `tik:`, `po:`, `lp:`.
- Формат: `<prefix>: labN: краткое действие` (пример: `tik: lab2: fix fork error path`).
- Один коммит = одно изменение.
- В PR указывайте: лабу/вариант, что сделано, как проверено, какие артефакты приложены.

## Reporting Rules
- Именование отчёта: `тегдисциплины-labN-report` (пример: `urvs-lab1-report`).
- Исходник отчёта: `тегдисциплины-labN-report.tex` (XeLaTeX), альтернативно `.docx`.
- Оформление: поля `3/2/2/1.5 см`, абзац `1 см`, основной текст по ширине.
- Подписи: таблицы сверху справа (`Таблица N`), рисунки снизу по центру (`Рис. N`), ссылки в тексте — `на рис. N`.
