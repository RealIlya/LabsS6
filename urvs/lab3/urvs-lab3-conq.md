# Контрольные вопросы — ЛР3

1. **Какова структура таблиц открытых файлов, файлов и описателей файлов после создания процесса?**  
   После `fork()` у родителя и потомка разные таблицы дескрипторов (на уровне процесса), но их записи ссылаются на общие open-file description в ядре. Поэтому состояние файлового объекта (offset, флаги) может быть общим.

2. **Для чего используются сигналы в ОС UNIX?**  
   Сигналы используются для асинхронного уведомления процесса о событиях: завершение дочернего процесса, прерывание, таймер, внешнее управление (`kill`) и т.д.

3. **Какие виды сигналов существуют в ОС UNIX?**  
   Сигналы условно делятся на:

- синхронные (возникают в результате выполнения процесса: например, `SIGSEGV`, `SIGFPE`);
- асинхронные (приходят извне: `SIGTERM`, `SIGINT`, `SIGCHLD`, `SIGALRM`).

4. **Для чего используются каналы?**  
   Каналы (`pipe`) используются для межпроцессного обмена данными в модели «поток байтов»: один процесс пишет, другой читает. Это простой механизм IPC для связанных процессов.

5. **Какие требования предъявляются к процессам для обмена через каналы?**  
   Обычно процессы должны быть родственными (канал создается до `fork()`, дескрипторы наследуются потомками). Для корректной работы нужно правильно закрывать неиспользуемые концы канала.

6. **Каков максимальный размер программного канала и почему?**  
   Размер ограничен буфером канала в ядре и зависит от системы (в Linux обычно десятки килобайт). Ограничение нужно для контроля памяти ядра и управления блокировками при `read/write`.
