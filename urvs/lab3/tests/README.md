# Тесты ЛР3 (вариант 2)

## Сборка

```bash
cd /mnt/c/Users/Admin/Desktop/LabsS6/urvs/lab3
gcc ./c/main.c -Wall -Wextra -Werror -std=c11 -o ./c/lab3.out
```

## Тест 1: позитивный запуск

```bash
./c/lab3.out 3
```

Ожидается:

- сообщения о создании и работе процессов `P0`, `P1`, `P2`;
- в выводе сначала идут записи от `P1`, затем от `P2`;
- итоговая строка `P0(...): all children finished`;
- код возврата `0`.

## Тест 2: запуск с параметром по умолчанию

```bash
./c/lab3.out
```

Ожидается:

- корректный обмен данными через канал `K1`;
- код возврата `0`.

## Тест 3: негативный запуск (`0` записей)

```bash
./c/lab3.out 0
echo $?
```

Ожидается:

- сообщение `error: records_per_child must be a positive integer` в `stderr`;
- код возврата `1`.

## Тест 4: негативный запуск (лишние аргументы)

```bash
./c/lab3.out 2 7
echo $?
```

Ожидается:

- сообщение `usage: ...` в `stderr`;
- код возврата `1`.
