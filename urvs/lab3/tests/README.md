## Тест 1: позитивный запуск с сигналом по умолчанию

```bash
./c/lab3.out
```

Ожидается:

- `P0` создает канал `K1` и процессы `P1`, `P2`;
- `P1` ждет сигнал от `P2`;
- `P2` первой записывает данные в `K1`, затем посылает сигнал процессу `P1`;
- `P1` после сигнала записывает свои данные в `K1`;
- `P0` печатает две полученные структуры и завершает работу с кодом `0`.

Фактический результат:

- последовательность работы соответствует схеме варианта 2;
- в канале сначала появляется сообщение от `P2`, затем от `P1`;
- программа завершается с кодом `0`.

## Тест 2: позитивный запуск с явным номером сигнала

```bash
./c/lab3.out 10
```

Ожидается:

- используется переданный перехватываемый сигнал;
- логика обмена через `K1` остается корректной;
- код возврата `0`.

Фактический результат:

- программа корректно отрабатывает с явным номером сигнала `10`;
- обмен данными и завершение процессов проходят штатно;
- код возврата `0`.

## Тест 3: негативный запуск с недопустимым номером сигнала

```bash
./c/lab3.out 0
echo $?
```

Ожидается:

- сообщение `error: signal_number must be a valid catchable signal` в `stderr`;
- код возврата `1`.

Фактический результат:

- программа выводит сообщение об ошибке;
- код возврата `1`.
