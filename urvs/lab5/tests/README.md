# Тесты ЛР5 (вариант 2)

## Сборка

```bash
cd /mnt/c/Users/Admin/Desktop/LabsS6/urvs/lab5
gcc ./c/main.c -Wall -Wextra -Werror -std=c11 -o ./c/lab5.out
```

## Тест 1: позитивный запуск с параметрами по умолчанию

```bash
./c/lab5.out
```

Ожидается:

- создание сегмента разделяемой памяти и набора семафоров;
- передача четверостиший от `P1` и `P2` в несбалансированных по времени циклах;
- получение родительским процессом всех фрагментов;
- вывод полного стихотворения после завершения детей;
- код возврата `0`.

Фактический результат:

- сегмент разделяемой памяти и набор семафоров создаются;
- `P1` и `P2` передают четверостишия, `P0` принимает их и выводит полное стихотворение;
- код возврата `0`.

## Тест 2: позитивный запуск с явными задержками

```bash
./c/lab5.out 80 220
```

Ожидается:

- тот же корректный результат при другой скорости работы дочерних процессов;
- код возврата `0`.

Фактический результат:

- программа корректно завершилась при задержках `80` и `220` мс;
- порядок поступления четверостиший изменился по времени, но итоговое стихотворение собрано правильно;
- код возврата `0`.
