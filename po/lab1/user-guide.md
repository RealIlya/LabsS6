# Руководство пользователя  
## Приложение «Конвертор p1_p2»

## 1. Назначение

Приложение предназначено для преобразования действительных чисел со знаком из системы счисления с основанием `p1` в систему счисления с основанием `p2`, где основания находятся в диапазоне `2..16`.

Поддерживаются:
- целая и дробная части числа;
- отрицательные числа;
- история выполненных преобразований;
- ввод с экранной клавиатуры и с физической клавиатуры.

## 2. Системные требования

- ОС: Windows 10/11.
- .NET: SDK/Runtime 8.0 (Windows Desktop).

## 3. Запуск приложения

### 3.1 Запуск из исходников

Из корня репозитория:

```powershell
dotnet run --project lab1/ui/ConverterLab1.WinForms/ConverterLab1.WinForms.csproj
```

### 3.2 Сборка

```powershell
dotnet build lab1/ConverterLab1.sln
```

## 4. Интерфейс

Главное окно содержит:
- поле `Исходное число` (верхнее);
- поле `Результат` (нижнее);
- `Основание с. сч. исходного числа` (`p1`) через `TrackBar` и `NumericUpDown`;
- `Основание с. сч. результата` (`p2`) через `TrackBar` и `NumericUpDown`;
- экранную клавиатуру;
- меню: `Выход`, `История`, `Справка`.

## 5. Назначение кнопок

| Кнопка | Действие |
|---|---|
| `0..9`, `A..F` | Ввод цифры |
| `.` | Разделитель дробной части |
| `BS` | Удалить символ справа |
| `CL` | Очистить ввод (сброс в `0`) |
| `+/-` | Сменить знак числа |
| `Execute` | Выполнить преобразование и записать результат в историю |

## 6. Клавиатурное управление

- `0..9`, `A..F`/`a..f` — ввод цифр.
- `.` или `,` — ввод разделителя дробной части.
- `Backspace` — `BS`.
- `Delete` — `CL`.
- `-` (основная клавиатура или NumPad) — `+/-`.
- `Enter` — `Execute`.

Недопустимые для текущего `p1` цифры блокируются.

## 7. Основной сценарий работы

1. Выберите `p1`.
2. Выберите `p2`.
3. Введите число в системе `p1`.
4. Нажмите `Execute`.
5. Получите результат в системе `p2`.
6. Откройте `История`, чтобы посмотреть журнал выполненных преобразований.

## 8. Особенности поведения

### 8.1 Изменение `p1`

При изменении основания исходного числа:
- поле ввода очищается;
- результат сбрасывается в `0`;
- состояние переходит в режим редактирования.

### 8.2 Изменение `p2`

- До первого успешного `Execute` результат остаётся `0`.
- После успешного `Execute` при изменении `p2` выполняется автоматический пересчёт результата.
- Автопересчёт при смене `p2` не добавляет запись в историю.

### 8.3 Когда пишется история

Запись добавляется только при нажатии `Execute`.

Формат записи:
`<исходное число> (<p1>) -> <результат> (<p2>)`

## 9. Точность и округление

Точность дробной части результата вычисляется автоматически на основе:
- количества знаков после разделителя в исходном числе;
- соотношения оснований `p1` и `p2`.

Важно: дробная часть формируется поразрядно до вычисленной точности, без отдельного пользовательского поля ручной настройки точности в интерфейсе.

## 10. Обработка ошибок

Если ввод некорректен, приложение показывает окно предупреждения (`MessageBox`), например:
- символ недопустим для выбранного основания;
- основание вне диапазона `2..16`;
- некорректная запись числа.

## 11. Окно «История»

Меню `История` открывает отдельное окно со списком выполненных преобразований текущего сеанса.

Если преобразований не было, выводится сообщение: `История пуста`.

## 12. Окно «Справка»

Меню `Справка` открывает окно с кратким описанием приложения и составом бригады.

## 13. Примеры

### Пример 1

- Ввод: `A5.E`, `p1=16`, `p2=10`.
- Результат: `165.875`.

### Пример 2

- Ввод: `-10.5`, `p1=10`, `p2=16`.
- Результат: `-A.8`.

### Пример 3

- Ввод: `25.5`, `p1=10`, `p2=16`, `Execute`.
- Смена `p2` на `2`.
- Результат автоматически изменится на `11001.1`, история не увеличится.

## 14. Ограничения

- Поддерживаются основания только `2..16`.
- Поддерживается только один разделитель дробной части.
- На выходе разделитель дробной части — точка (`.`).
- На экранной клавиатуре доступны цифры `A..F`, но они активны только при `p1 > 10`.

## 15. Быстрый чек-лист пользователя

1. Выбрать `p1`.
2. Выбрать `p2`.
3. Ввести число.
4. Нажать `Execute`.
5. Проверить результат и при необходимости открыть `История`.
