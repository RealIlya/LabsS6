# Контрольные вопросы — лабораторная работа №2

## 1. Что такое инкапсуляция?

Инкапсуляция — это объединение данных и методов их обработки в одном классе с ограничением прямого доступа к внутреннему состоянию. Внешний код работает с объектом через публичный интерфейс (`public` методы/свойства), а детали реализации скрываются (`private`, `protected`).

## 2. Как синтаксически представлено поле в описании класса?

Поле — это переменная уровня класса, объявленная в теле класса с указанием модификатора доступа и типа.
Пример: `private readonly List<Abonent> items = new();`.

## 3. Как синтаксически представлен метод в описании класса?

Метод объявляется сигнатурой вида: `[модификатор] [тип_результата] Имя(параметры)` и телом в фигурных скобках.
Пример: `public void AddRecord(string name, string number) { ... }`.

## 4. Как синтаксически представлено простое свойство в описании класса?

Свойство — это член класса с `get`/`set` для контролируемого доступа к данным.
Пример: `public int RecordsCount => items.Count;` (только `get`).

## 5. Особенности описания методов класса?

Методы описываются с учётом:

- модификатора доступа (`public`, `private`);
- возвращаемого типа (`void`, `int`, `string`, пользовательский тип);
- параметров и их типов;
- контрактов на вход/выход (валидация, исключения);
- принадлежности экземпляру (`instance`) или классу (`static`).

## 6. Особенности описания и назначение конструктора класса?

Конструктор инициализирует корректное начальное состояние объекта и вызывается при создании экземпляра (`new`).
Особенности:

- имя конструктора совпадает с именем класса;
- не имеет возвращаемого типа;
- может быть перегружен;
- часто выполняет валидацию исходных данных.

## 7. Видимость идентификаторов в описании класса?

Видимость задаётся модификаторами доступа:

- `public` — доступен из любого места;
- `private` — доступен только внутри класса;
- `protected` — доступен в классе и его наследниках;
- `internal` — доступен внутри сборки;
- `protected internal`, `private protected` — комбинированные варианты.

## 8. Особенности вызова методов применительно к объектам класса?

Экземплярные методы вызываются у конкретного объекта: `obj.Method()`.
Статические методы вызываются у типа: `Type.Method()`.
Корректный вызов требует соблюдения сигнатуры метода, допустимых значений параметров и текущего состояния объекта.
