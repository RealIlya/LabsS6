# Саммари по теории к лабораторной работе №3

## Тема

Тема лабораторной работы для титульного листа: `Калькулятор p-ичных чисел`.

Такая формулировка следует из варианта лабораторной работы: в методических материалах явно выделен раздел `Вариант 1 – «Калькулятор p-ичных чисел»`. Для титульника это точнее, чем общее слово `Калькулятор`, потому что отражает конкретный тип чисел и специфику задания.

## Цель работы

Цель работы состоит в формировании практических навыков:

- проектирования программ в технологии абстрактных типов данных;
- реализации абстрактных типов данных с помощью классов;
- построения графического интерфейса для работы с реализованными типами данных.

## Общая постановка

Необходимо разработать приложение под Windows «Калькулятор», которое выполняет вычисления над числами, заданными в соответствии с вариантом. Для рассматриваемого варианта используются действительные числа, представленные в системе счисления с основанием `p`.

## Основные теоретические положения

### 1. Абстрактный тип данных

Абстрактный тип данных задаёт модель данных через набор допустимых значений и набор операций над ними. Пользователь типа работает с внешней спецификацией: что делает тип и какие операции он поддерживает. Внутреннее представление скрыто внутри класса.

### 2. Инкапсуляция

Инкапсуляция означает объединение данных и операций над ними в одном классе, а также сокрытие внутренней реализации. Внешний код использует открытый интерфейс класса, не обращаясь напрямую к его внутреннему состоянию.

### 3. Представление p-ичного числа

Для варианта `Калькулятор p-ичных чисел` число задаётся в формате фиксированной точки:

- возможен знак `-`;
- целая часть записывается цифрами выбранной системы счисления;
- дробная часть отделяется разделителем;
- основание системы счисления находится в диапазоне `2..16`.

В методичке отдельно указано, что основание является настраиваемым параметром.

### 4. Связь основания системы счисления и интерфейса

Кнопки ввода цифр должны зависеть от выбранного основания. Пользователю должны быть доступны только те цифры, которые допустимы в текущей системе счисления.

Примеры:

- при основании `2` доступны только `0` и `1`;
- при основании `10` доступны `0..9`;
- при основании `16` доступны `0..9`, `A..F`.

### 5. Перевод числа при смене основания

Методичка прямо требует, чтобы при смене системы счисления отображаемое число выражалось в новой системе счисления. Это означает, что изменение основания должно приводить не к очистке поля, а к переводу текущего значения в новую форму записи.

Пример:

- при основании `10` значение `10.5`;
- после переключения на основание `2` это же значение должно отображаться как `1010.1`.

### 6. Основные операции калькулятора

Калькулятор должен поддерживать:

- бинарные операции `+`, `-`, `*`, `/`;
- функции над одним операндом;
- ввод и редактирование числа;
- память;
- буфер обмена;
- настройку параметров;
- справку.

### 7. Память калькулятора

Память хранит одно значение и имеет два состояния:

- включена;
- выключена.

Основные команды памяти:

- `MC` — очистить память;
- `MS` — сохранить текущее значение;
- `MR` — прочитать значение из памяти;
- `M+` — прибавить текущее значение к содержимому памяти.

### 8. Буфер обмена

Меню `Правка` используется для работы с буфером обмена. Типовые команды:

- копировать;
- вставить.

Эти операции позволяют переносить текущее значение между калькулятором и внешними приложениями.

### 9. Ввод и редактирование

Калькулятор должен поддерживать ввод:

- мышью через командные кнопки;
- с клавиатуры через цифровые и буквенно-цифровые клавиши.

Для редактирования необходимы операции:

- удаление последнего символа;
- очистка текущего значения;
- добавление цифры;
- добавление разделителя;
- изменение знака числа.

### 10. Структура решения

С практической точки зрения решение удобно делить на несколько взаимосвязанных частей:

- тип числа;
- редактор числа;
- процессор операций;
- память;
- управление калькулятором;
- графический интерфейс.

Такое разделение соответствует идее объектно-ориентированного проектирования и упрощает тестирование.
