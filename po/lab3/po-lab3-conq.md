# Контрольные вопросы к лабораторной работе №3

## 1. Что такое инкапсуляция?

Инкапсуляция — это объединение данных и операций над ними в одном классе с ограничением прямого доступа к внутреннему состоянию объекта. В результате объект предоставляет внешний интерфейс, через который выполняется работа с его данными, а детали внутренней реализации скрываются.

## 2. Как синтаксически представлено поле в описании класса?

Поле класса синтаксически задаётся как объявление переменной внутри описания класса. В общем виде это запись вида:

`тип имяПоля;`

Например:

```cpp
double n;
int b;
int c;
```

Такое объявление определяет состояние объекта класса.

## 3. Как синтаксически представлен метод в описании класса?

Метод класса синтаксически задаётся как объявление функции внутри описания класса. В общем виде это запись вида:

`типРезультата имяМетода(списокПараметров);`

Например:

```cpp
TPNumber Add(TPNumber d);
string ToString();
void SetBase(int b);
```

Метод задаёт операцию, которую можно выполнить над объектом класса.

## 4. В чём состоит назначение конструктора?

Конструктор предназначен для создания и начальной инициализации объекта класса. Он обеспечивает перевод объекта в корректное начальное состояние сразу после создания.

Применительно к данной лабораторной работе конструктор используется для:

- задания начального значения числа;
- установки основания системы счисления;
- установки точности представления;
- подготовки объекта к дальнейшей работе без дополнительной инициализации извне.
