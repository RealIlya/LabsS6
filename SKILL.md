# Skills Spec For Other Models

Этот файл задаёт минимальный набор скиллов для любых нейросетей/агентов, работающих с лабами в этой директории.

## Требуемые скиллы

1. `pdf-docx-parser`
2. `docx-report-layout`
3. `lab-control-questions`
4. `lab-title-and-final-pdf`

## 1) pdf-docx-parser

- Назначение: извлекать текст, структуру и изображения из `pdf/docx` в читаемый `md/txt`.
- Когда вызывать: разбор методички, поиск требований, OCR сканов.
- Состав:
  - `SKILL.md`: правила извлечения и проверки качества распознавания.
  - `scripts/`: `extract_docx.ps1`, `extract_pdf.ps1`, `ocr_pdf.ps1`.
  - `references/`: `tools.md` (pdftotext/pdftoppm/tesseract/pandoc), `quality-checklist.md`.
  - `assets/`: опционально шаблоны для структуры выгрузки.

## 2) docx-report-layout

- Назначение: собирать и доводить отчёты до требований преподавателя в `docx`.
- Когда вызывать: финальная вёрстка отчёта из `md/tex`.
- Состав:
  - `SKILL.md`: правила оформления (поля, абзац, выравнивание, заголовки, код-блоки, подписи).
  - `scripts/`: `build_report_docx.py`, `quick_validate.py`.
  - `references/`: `format-rules.md`, `troubleshooting.md`.
  - `assets/`: `reference.docx`, при необходимости стили/шаблоны.

## 3) lab-control-questions

- Назначение: готовить ответы на контрольные вопросы в отдельном `md`.
- Когда вызывать: если в файлах лабы есть раздел `Контрольные вопросы`.
- Состав:
  - `SKILL.md`: формат ответов (умеренно строгий, кратко и по существу).
  - `scripts/`: `extract_questions.ps1`, `build_answers_md.ps1`.
  - `references/`: приоритет источников (сначала теория из лабы/методички, затем проверяемые интернет-источники).
  - `assets/`: шаблон `control-questions.md`.

## 4) lab-title-and-final-pdf

- Назначение: собирать титульник и итоговый `report.pdf`.
- Когда вызывать: только по команде пользователя `сделай полный отчёт`.
- Состав:
  - `SKILL.md`: пошаговый пайплайн и условия остановки.
  - `scripts/`: `build_title_pdf.ps1`, `merge_report_pdf.ps1`, `add_page_numbers.ps1`.
  - `references/`: правила нумерации и проверки итогового PDF.
  - `assets/`: HTML/CSS шаблон титульника (`$title-folder`), шаблоны конфигов.

## Обязательные правила для скилла `lab-title-and-final-pdf`

1. Брать исходник титульника из `$title-folder` (`html+css`).
2. Для каждой лабы задавать корректные: заголовок, номер лабы, название дисциплины.
3. Проверять `tutors-list.txt` в папке предмета.
4. Если `tutors-list.txt` отсутствует: сообщать пользователю и останавливать сборку отчёта.
5. Сначала собирать `title.pdf`.
6. Собирать итоговый `report.pdf` только после подтверждения пользователя, что титульник и отчёт корректны.
7. В итоговом `report.pdf` титульный лист без номера; первая страница отчёта имеет номер `1`.
