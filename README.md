# Labs Sem 6

## Общая информация

Работа выполняется в ветке `develop`, либо возможно сделать ветку от `develop` с именем "Тег дисциплины" и делать там.

| Тег дисциплины | Название дисциплины                                              |
| -------------- | ---------------------------------------------------------------- |
| `urvs`         | Управление ресурсами в вычислительных системах                   |
| `web`          | Разработка web-приложений и распределенных информационных систем |
| `mo`           | Методы оптимизации                                               |
| `tik`          | Теория информации и криптография                                 |
| `po`           | Технологии разработки программного обеспечения                   |
| `lp`           | Введение в искусственный интеллект и логическое программирование |
| `pisa`         | Проектирование интерфейсов и системный анализ                    |
