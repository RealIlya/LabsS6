## 1. Алгоритм простого случайного поиска

**Алгоритм простого случайного поиска** — это метод глобальной оптимизации, основанный на случайной генерации точек в допустимой области и выборе точки с наилучшим значением целевой функции.

### Описание алгоритма:

1. В заданной области $D$ по равномерному закону генерируется случайная точка $x_1$ и вычисляется значение функции $y_1 = f(x_1)$.

2. Аналогично генерируется следующая случайная точка $x_2$ и вычисляется $y_2 = f(x_2)$.

3. Запоминается минимальное (или максимальное, в зависимости от задачи) значение функции и соответствующая ему точка.

4. Процесс повторяется $N$ раз, где $N$ определяется заданной точностью и требуемой вероятностью успеха.

5. После $N$ испытаний в качестве решения берется точка с наилучшим найденным значением функции.

### Оценка числа испытаний:

Для $n$-мерного прямоугольника $x \in [A, B]$ с объемом $V = \prod_{i=1}^{n} (B_i - A_i)$ и требуемой точностью $\varepsilon_i$ по каждой переменной (объем окрестности оптимума $V_\varepsilon = \prod_{i=1}^{n} \varepsilon_i$):

Вероятность попадания в окрестность оптимума при одном испытании:
$$P_\varepsilon = \frac{V_\varepsilon}{V}$$

Вероятность нахождения решения за $N$ испытаний:
$$P = 1 - (1 - P_\varepsilon)^N$$

Необходимое число испытаний:
$$N \geq \frac{\ln(1 - P)}{\ln(1 - P_\varepsilon)}$$

### Достоинства:
- Гарантирует нахождение глобального экстремума с заданной вероятностью
- Не требует вычисления производных
- Не зависит от структуры и свойств целевой функции
- Простота реализации

### Недостатки:
- Крайне низкая эффективность (экспоненциальный рост числа вычислений при увеличении точности или размерности)
- Не использует информацию о структуре функции
- Практически неприменим при высоких требованиях к точности

## 2. Алгоритм с парной пробой

**Алгоритм с парной пробой** — это метод направленного случайного поиска, в котором используется случайное направление с выбором лучшей из двух точек.

### Описание алгоритма:

1. Задается начальная точка $x^{(0)}$ и начальный шаг $h_0$.

2. **На каждой итерации $k$:**
   - Генерируется случайный единичный вектор направления $\xi^{(k)}$ (например, на сфере единичного радиуса)
   - Вычисляются две пробные точки:
     - $x_1 = x^{(k)} + h_k \cdot \xi^{(k)}$ (движение вперед)
     - $x_2 = x^{(k)} - h_k \cdot \xi^{(k)}$ (движение назад)
   - Вычисляются значения функции: $f_1 = f(x_1)$ и $f_2 = f(x_2)$

3. **Выбор новой точки:**
   - Если $f_1 < f(x^{(k)})$ или $f_2 < f(x^{(k)})$, то выбирается точка с меньшим значением функции: $x^{(k+1)} = \arg\min\{f_1, f_2\}$ (успешный шаг, можно увеличить $h$)
   - Если оба значения хуже текущего, точка не меняется: $x^{(k+1)} = x^{(k)}$ (неудачный шаг, следует уменьшить $h$)

4. **Адаптация шага:**
   - При успешном шаге: $h_{k+1} = \alpha \cdot h_k$, где $\alpha > 1$ (например, $\alpha = 1.5$)
   - При неудачном шаге: $h_{k+1} = \beta \cdot h_k$, где $0 < \beta < 1$ (например, $\beta = 0.5$)

5. Алгоритм останавливается, когда шаг $h_k$ становится меньше заданной точности или достигнуто максимальное число итераций.

### Достоинства:
- Не требует вычисления производных
- Адаптируется к рельефу функции через изменение шага
- Более эффективен, чем простой случайный поиск
- Проверка двух противоположных направлений повышает вероятность улучшения

### Недостатки:
- Сходится к локальному экстремуму (не гарантирует глобальный оптимум)
- Эффективность зависит от выбора параметров $\alpha$ и $\beta$
- Может быть медленным вблизи оптимума

## 3. Алгоритм статистического градиента

**Алгоритм статистического градиента** (метод Качмажа, метод стохастической аппроксимации) — это метод направленного случайного поиска, который использует статистическую оценку градиента функции на основе случайных возмущений.

### Описание алгоритма:

1. Задается начальная точка $x^{(0)}$, начальный шаг $h_0$ и малое возмущение $\delta$.

2. **На каждой итерации $k$:**
   - Генерируется случайный единичный вектор возмущения $\xi^{(k)}$ (из равномерного распределения на единичной сфере)
   - Вычисляются значения функции в двух близких точках:
     - $f_+ = f(x^{(k)} + \delta \cdot \xi^{(k)})$
     - $f_- = f(x^{(k)} - \delta \cdot \xi^{(k)})$

3. **Оценка градиента:**
   Статистическая оценка компоненты градиента в направлении $\xi^{(k)}$:
   $$\tilde{g}^{(k)} = \frac{f_+ - f_-}{2\delta}$$
   
   Приближенный градиент:
   $$\nabla f \approx \tilde{g}^{(k)} \cdot \xi^{(k)}$$

4. **Движение в направлении антиградиента:**
   $$x^{(k+1)} = x^{(k)} - h_k \cdot \tilde{g}^{(k)} \cdot \xi^{(k)}$$
   
   где $h_k$ — шаг метода (может уменьшаться с ростом $k$).

5. Алгоритм останавливается при выполнении критерия сходимости: $|x^{(k+1)} - x^{(k)}| < \varepsilon$ или $|f(x^{(k+1)}) - f(x^{(k)})| < \varepsilon_f$.

### Варианты реализации:

- **Метод Кифера-Вольфовица:** $h_k = \frac{h_0}{k^\alpha}$, $\delta_k = \frac{\delta_0}{k^\beta}$, где $0.5 < \alpha < 1$, $0 < \beta < \alpha$

- **Усреднение по нескольким направлениям:** На каждой итерации генерируется несколько случайных направлений, оценки градиента усредняются.

### Достоинства:
- Не требует аналитического вычисления градиента
- Применим к негладким и зашумленным функциям
- Более эффективен, чем методы нулевого порядка на гладких функциях
- Может избегать узких оврагов благодаря случайности направлений

### Недостатки:
- Требует выбора двух параметров: $h$ (шаг) и $\delta$ (возмущение)
- Сходимость медленнее, чем у детерминированных градиентных методов
- Приводит к локальному экстремуму (не гарантирует глобальный)
- Чувствителен к выбору последовательностей $\{h_k\}$ и $\{\delta_k\}$

## 4. Алгоритм наилучшей пробы с направляющим гиперквадратом

**Алгоритм наилучшей пробы с направляющим гиперквадратом** (метод Растригина) — это метод направленного случайного поиска, который использует адаптивное распределение пробных точек на основе накопленной информации об успешных направлениях.

### Описание алгоритма:

1. **Инициализация:**
   - Задается начальная точка $x^{(0)}$
   - Создается начальный направляющий гиперквадрат (матрица направлений) $H^{(0)} = h_0 \cdot I$, где $I$ — единичная матрица, $h_0$ — начальный размер

2. **На каждой итерации $k$:**
   
   **а) Генерация пробных точек:**
   - Генерируется $N$ случайных точек внутри направляющего гиперквадрата:
     $$x_i = x^{(k)} + H^{(k)} \cdot \xi_i, \quad i = 1, \ldots, N$$
     где $\xi_i$ — случайные векторы с компонентами из интервала $[-1, 1]$
   
   **б) Вычисление значений функции:**
   - Вычисляются $f_i = f(x_i)$ для всех пробных точек
   
   **в) Выбор наилучшей точки:**
   - Определяется $i^* = \arg\min\{f_1, \ldots, f_N\}$
   - Если $f_{i^*} < f(x^{(k)})$, то $x^{(k+1)} = x_{i^*}$ (успешный шаг)
   - Иначе $x^{(k+1)} = x^{(k)}$ (неудачный шаг)

3. **Адаптация направляющего гиперквадрата:**
   
   **При успешном шаге:**
   - Гиперквадрат растягивается в направлении успешного движения:
     $$H^{(k+1)} = H^{(k)} + \alpha \cdot (x^{(k+1)} - x^{(k)}) \otimes e_1$$
     где $\alpha > 0$ — коэффициент усиления, $e_1$ — первый базисный вектор (или направление максимальной вариации)
   
   **При неудачном шаге:**
   - Гиперквадрат сжимается:
     $$H^{(k+1)} = \beta \cdot H^{(k)}, \quad 0 < \beta < 1$$

4. **Дополнительно:** Периодически (например, каждые $n$ итераций) гиперквадрат может ортогонализироваться (процедура Грама-Шмидта) для избежания вырождения.

5. Алгоритм останавливается, когда размер гиперквадрата становится меньше заданной точности или достигнуто максимальное число итераций.

### Достоинства:
- Адаптируется к локальной структуре функции (овражность, направления быстрого изменения)
- Более эффективен, чем метод с парной пробой, благодаря накоплению информации о направлениях
- Не требует вычисления производных
- Хорошо работает на овражных функциях

### Недостатки:
- Требует генерации и вычисления функции в $N$ точках на каждой итерации (больше вычислений)
- Сложность реализации и настройки параметров ($N$, $\alpha$, $\beta$)
- Сходится к локальному экстремуму
- Может вырождаться при неправильном выборе параметров адаптации

## 5. Алгоритмы глобального поиска

**Алгоритмы глобального поиска** — это методы, направленные на нахождение глобального экстремума многоэкстремальной функции путем комбинирования случайного поиска и детерминированных методов локальной оптимизации.

### 5.1. Алгоритм 1: Многократный запуск (Multi-start)

**Принцип:** Запуск локального метода оптимизации из множества случайных начальных точек.

**Алгоритм:**
1. В допустимой области $D$ случайным образом выбирается точка $x_1 \in D$
2. Из точки $x_1$ запускается детерминированный метод локальной оптимизации (например, метод Нелдера-Мида, градиентный спуск)
3. Находится локальный минимум $x_1^* \in D$, запоминается его значение $f(x_1^*)$
4. Процесс повторяется $m$ раз: выбирается новая случайная точка $x_i$, из нее производится спуск в локальный минимум $x_i^*$
5. Среди всех найденных локальных минимумов выбирается точка с наименьшим значением функции

**Критерий остановки:** 
- Выполнено $m$ запусков
- Или: $k$ последовательных запусков не дали улучшения лучшего найденного значения

**Достоинства:**
- Простота реализации
- Высокая эффективность при правильном выборе $m$
- Хорошо распараллеливается

**Недостатки:**
- Нет гарантии нахождения глобального минимума
- Может многократно находить один и тот же локальный минимум
- Эффективность зависит от числа запусков $m$

### 5.2. Алгоритм 2: Случайный поиск с последующим спуском

**Принцип:** Систематическое улучшение найденных локальных минимумов через случайный поиск лучших стартовых точек.

**Алгоритм:**
1. Выбирается случайная точка $x_1 \in D$, из нее производится спуск в локальный минимум $x_1^*$
2. Запоминается текущий лучший минимум: $x_{best} = x_1^*$, $f_{best} = f(x_1^*)$
3. **Цикл улучшения:**
   - Генерируются случайные точки $x \in D$ до тех пор, пока не найдется точка с $f(x) < f_{best}$
   - Из найденной точки $x$ производится локальный спуск в $x^*$
   - Если $f(x^*) < f_{best}$, обновляется: $x_{best} = x^*$, $f_{best} = f(x^*)$
   - Иначе счетчик неудач увеличивается на 1
4. Алгоритм останавливается после $m$ последовательных неудач (не удалось найти лучший минимум)

**Достоинства:**
- Гарантированное улучшение на каждом шаге (монотонность)
- Систематический переход к более глубоким минимумам

**Недостатки:**
- Может требовать большого числа случайных проб на этапе поиска улучшающей точки
- Неэффективен, если после нахождения глобального минимума продолжается поиск улучшающих точек

### 5.3. Алгоритм 3: Выход из области притяжения

**Принцип:** Систематический выход из области притяжения текущего локального минимума для поиска других локальных минимумов.

**Алгоритм:**
1. Выбирается случайная начальная точка $x_0 \in D$, производится спуск в локальный минимум $x_1^*$
2. Запоминается лучший минимум: $x_{best} = x_1^*$
3. **Цикл выхода из области притяжения:**
   - Из текущего локального минимума $x_i^*$ движемся в случайном направлении на расстояние $h$:
     $$x_0^{new} = x_i^* + h \cdot \xi$$
     где $\xi$ — случайный единичный вектор
   - Из точки $x_0^{new}$ производится спуск в новый локальный минимум $x_{i+1}^*$
   - Если $f(x_{i+1}^*) < f(x_{best})$, обновляется $x_{best} = x_{i+1}^*$ и счетчик неудач обнуляется
   - Иначе счетчик неудач увеличивается
4. Алгоритм останавливается после $m$ последовательных неудачных попыток найти лучший минимум

**Вариант:** Можно двигаться в направлении $(x_i^* - x_0)$, продолжая траекторию спуска.

**Достоинства:**
- Систематическое исследование пространства решений
- Хорошо работает для функций с изолированными локальными минимумами
- Использует информацию о предыдущих минимумах

**Недостатки:**
- Критически зависит от выбора параметра $h$ (длины шага выхода)
- Может застревать в окрестности сильных локальных минимумов
- При малом $h$ не выходит из области притяжения, при большом $h$ может пропускать минимумы

### 5.4. Общие особенности алгоритмов глобального поиска

**Сравнение подходов:**
- **Алгоритм 1** — наиболее простой и универсальный, хорошо подходит для начального исследования
- **Алгоритм 2** — более систематический, гарантирует монотонное улучшение, но может быть медленным
- **Алгоритм 3** — эффективен для функций с четко выраженными областями притяжения, требует настройки

**Практические рекомендации:**
1. Для большинства задач начинать с Алгоритма 1 с достаточно большим $m$ (50-100)
2. При наличии вычислительных ресурсов использовать Алгоритм 2 для гарантии качества решения
3. Алгоритм 3 применять после анализа структуры функции и подбора параметра $h$
4. Комбинировать подходы: Алгоритм 1 для первичного поиска, затем Алгоритм 3 для уточнения

**Важное замечание:** Ни один из этих алгоритмов не дает математической гарантии нахождения глобального минимума (в отличие от простого случайного поиска), но на практике они гораздо эффективнее.

## Выводы

Статистические методы поиска представляют собой важный класс алгоритмов оптимизации, особенно полезных для:
- Задач с негладкими или недифференцируемыми функциями
- Многоэкстремальных функций (поиск глобального экстремума)
- Задач, где вычисление производных затруднено или невозможно
- Исследовательского анализа неизвестных функций

Выбор конкретного метода зависит от:
- Требований к гарантии глобального оптимума
- Доступных вычислительных ресурсов
- Структуры целевой функции
- Требуемой точности решения

На практике наиболее эффективны гибридные подходы, сочетающие случайный поиск для глобального исследования и детерминированные методы для локального уточнения.
