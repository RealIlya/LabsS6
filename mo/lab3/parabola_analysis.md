# Анализ эффективности метода парабол для одномерной минимизации

## Введение

В данной работе стандартный метод `minimize_scalar` из SciPy (комбинация золотого сечения и парабол) был заменён на **чистый метод парабол** (квадратичная интерполяция) для одномерного поиска вдоль направления спуска.

## Алгоритм метода парабол

Метод использует три точки $(a, f(a))$, $(b, f(b))$, $(c, f(c))$ для построения интерполяционной параболы:

$$P(\lambda) = A\lambda^2 + B\lambda + C$$

Минимум параболы находится по формуле:

$$\lambda^* = b - \frac{1}{2} \cdot \frac{(b-a)^2(f(b)-f(c)) - (b-c)^2(f(b)-f(a))}{(b-a)(f(b)-f(c)) - (b-c)(f(b)-f(a))}$$

## Выводы

### 1. Квадратичная функция (точный поиск)
Метод парабол показывает стабильное улучшение на **~12%** для всех методов. Это объясняется тем, что для квадратичной функции парабола точно аппроксимирует целевую функцию, и минимум находится за меньшее число итераций line search.

### 2. Функция Розенброка
- **Наискорейший спуск**: достигнуто **кратное улучшение (52.1% меньше вычислений)**. Метод парабол быстрее находит оптимальный шаг вдоль антиградиента в узком овраге.
- **Сопряжённые градиенты**: небольшой рост вычислений (+2–4%), что связано с особенностями работы метода парабол на неквадратичных функциях.
- **Методы переменной метрики**: Бройден показывает рост (+14.8%), DFP — улучшение (−6.3%).

### 3. Грубый поиск (ls_tol = 0.1)
Наиболее впечатляющие результаты:
- **Сопряжённые градиенты (Полак-Рибьер)**: **−91.5%** вычислений (с 319 до 27)
- **Сопряжённые градиенты (Флетчер-Ривс)**: **−86.5%** (с 200 до 27)
- **Наискорейший спуск**: **−83.1%** (с 640 до 108)

Метод парабол **стабилизировал работу алгоритмов** — число итераций всех методов сравнялось с точным поиском (3 итерации для методов сопряжённых градиентов и переменной метрики).

## Преимущества метода парабол

| Преимущество | Описание |
|--------------|----------|
| Быстрая сходимость | Для гладких функций — сверхлинейная скорость |
| Меньше вычислений | Не требует дополнительных вызовов градиента |
| Простота реализации | Формула через 3 точки, без внешних зависимостей |
| Эффективность на квадратичных функциях | Точная аппроксимация параболой |
| Устойчивость к ls_tol | Менее чувствителен к снижению точности |

## Недостатки

| Недостаток | Описание |
|------------|----------|
| ❌ Требует унимодальности | Необходим брекетинг интервала |
| ❌ Чувствительность к начальному приближению | Может сходиться к локальному минимуму |
| ❌ Деление на ноль | Требуется защита при вырожденных случаях |

---

## Итог

Метод парабол **оптимизирует вычисления** за счёт:
1. **Отказа от универсального алгоритма** SciPy в пользу специализированного
2. **Меньшего числа вычислений функции** на каждой итерации line search
3. **Более быстрой сходимости** на гладких функциях

**Наибольший эффект:**
- **Функция Розенброка (наискорейший спуск)**: сокращение на **29085 вычислений (52.1%)**
- **Грубый поиск**: сокращение до **91.5%** для методов сопряжённых градиентов
