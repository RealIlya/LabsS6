# Лабораторная работа 2 (вариант 2)

Приложение реализовано на `Python` с UI на `Tkinter` и разделением на слои:
- `src/core` - криптологика (OTP, скремблеры, анализ ПСП);
- `src/ui` - графический интерфейс;
- `src/io_utils.py` - файловые операции;
- `tests` - автотесты core-логики.

## Запуск

```bash
cd lab2
python src/main.py
```

## Что реализовано

1. Шифрование и дешифрование в режиме однократного гаммирования.
2. Шифрование и дешифрование с использованием скремблеров LFSR.
3. Представления данных `SYM/HEX/BIN` для ввода, просмотра и изменения.
4. Исследование последовательности скремблера:
- период;
- критерий `chi^2`;
- сбалансированность;
- цикличность (уникальность циклических сдвигов);
- автокорреляция.

## Скремблеры (вариант 2)

В коде зафиксированы только полиномы варианта 2:
- скремблер 1: `x9 + x3 + 1`
- скремблер 2: `x9 + x4 + 1`

В UI можно выбрать только скремблер `1` или `2`; полиномы фиксированы логикой приложения.
