# Конспект теории к лабораторной работе №2

## Тема и цель

Лабораторная посвящена двум направлениям:

- однократное гаммирование (one-time pad, схема Вернама);
- шифрование потока при помощи скремблера на базе LFSR.

Цель — понять свойства потокового шифрования и исследовать характеристики псевдослучайной последовательности.

## Однократное гаммирование

Гаммирование — побитовое наложение ключевой последовательности (гаммы) на данные операцией XOR.

Основные формулы:

- шифрование: $C_i = P_i \oplus K_i$;
- дешифрование: $P_i = C_i \oplus K_i$;
- восстановление ключа при известных $C_i$ и $P_i$: $K_i = C_i \oplus P_i$.

Свойство симметричности возникает из-за того, что $a \oplus b \oplus b = a$.

## Абсолютная стойкость по Шеннону

Однократное гаммирование теоретически абсолютно стойко только при одновременном выполнении условий:

- ключ истинно случаен;
- длина ключа равна длине сообщения;
- ключ используется строго один раз и затем уничтожается.

Нарушение любого условия резко снижает криптостойкость.

## Опасность повторного использования ключа

Если один ключ применен к двум сообщениям:

$C_1 = P_1 \oplus K$, $C_2 = P_2 \oplus K$,

то

$C_1 \oplus C_2 = P_1 \oplus P_2$.

Это позволяет атакующему извлекать структуру открытых текстов и постепенно восстанавливать сообщения (особенно при наличии шаблонов/известных фрагментов).

## Скремблер и LFSR

LFSR (линейный регистр сдвига с обратной связью) генерирует битовый поток на основе текущего состояния регистра и выбранного полинома обратной связи.

Общее описание:

- регистр длины $n$ хранит $n$ бит состояния;
- на каждом такте биты сдвигаются;
- новый старший бит вычисляется как XOR выбранных разрядов (тапов);
- выходной бит формирует гамму.

Полином обратной связи задает структуру тапов, например:

$f(x) = x^n + a_{n-1}x^{n-1} + \dots + a_1x + a_0$, где $a_i \in \{0,1\}$.

Для варианта 2 в работе используются:

- скремблер 1: $x^9 + x^3 + 1$;
- скремблер 2: $x^9 + x^4 + 1$.

## Свойства ПСП, которые исследуются в ЛР

- период последовательности;
- сбалансированность (доли 0 и 1 близки);
- цикличность/структура серий;
- автокорреляционные свойства;
- критерий $\chi^2$ как проверка статистического поведения.

Для максимального периода используют примитивные полиномы; теоретический верхний предел периода для $n$-разрядного регистра — $2^n - 1$ (для ненулевых состояний).

## Практические выводы для ЛР

- OTP показывает эталон стойкости, но неудобен в применении из-за требований к ключу.
- LFSR удобен для генерации потока, но требует аккуратного выбора полинома и начального состояния.
- Основной учебный результат ЛР — связь между формальными свойствами ПСП и реальной стойкостью потокового шифрования.
