# Контрольные вопросы — Лабораторная работа 2

## 1. Преимущества и недостатки однократного гаммирования

**Преимущества:**
- при корректных условиях даёт абсолютную (совершенную) стойкость;
- простое шифрование/дешифрование: $C = P \oplus K$, $P = C \oplus K$;
- высокая скорость, так как используется только XOR.

**Недостатки:**
- ключ должен быть действительно случайным;
- длина ключа должна быть не меньше длины сообщения;
- ключ нельзя использовать повторно;
- проблема безопасного хранения и передачи длинных ключей.

## 2. Почему размерность открытого текста должна совпадать с ключом?

Операция гаммирования выполняется побитово:  
$C_i = P_i \oplus K_i$.  
Чтобы получить каждый бит шифротекста, нужен соответствующий бит ключа.  
Поэтому для одноразового гаммирования требуется $|K| = |P|$.

## 3. Как по открытому тексту и шифротексту получить ключ?

Из формулы $C = P \oplus K$ следует:

$$
K = P \oplus C.
$$

То есть ключ вычисляется прямым XOR открытого текста и шифротекста.

## 4. Необходимые и достаточные условия абсолютной стойкости шифра

Для схемы одноразового гаммирования (по Шеннону):
- ключ равновероятно выбирается из множества всех двоичных строк нужной длины;
- ключ статистически независим от открытого текста;
- ключ используется только один раз;
- длина ключа не меньше длины сообщения.

Эквивалентный критерий: для любого наблюдаемого шифротекста апостериорные вероятности открытых текстов не меняются.

## 5. Как, зная текст одного из сообщений ($P_1$ или $P_2$), определить другое, не пытаясь определить ключ?

Если один и тот же ключ ошибочно применён к двум сообщениям:

$$
C_1 = P_1 \oplus K,\quad C_2 = P_2 \oplus K.
$$

Тогда:

$$
C_1 \oplus C_2 = P_1 \oplus P_2.
$$

Отсюда:

$$
P_2 = P_1 \oplus C_1 \oplus C_2
$$

(аналогично можно найти $P_1$, если известно $P_2$).

## 6. Преимущества и недостатки использования скремблера

**Преимущества:**
- гамма генерируется из короткого начального состояния;
- не требуется хранить ключ длиной с сообщение;
- легко реализуется программно и аппаратно.

**Недостатки:**
- скремблер детерминирован: при известной структуре и seed последовательность полностью восстанавливается;
- при малом периоде и плохих полиномах падает стойкость;
- линейные LFSR уязвимы для криптоанализа без дополнительных нелинейных механизмов.

## 7. Свойства псевдослучайной последовательности скремблера

Последовательность должна обладать следующими свойствами:
- большой период;
- близкая к равномерной частота нулей и единиц (сбалансированность);
- слабая корреляция между сдвинутыми копиями (низкая автокорреляция);
- отсутствие простых закономерностей и предсказуемости;
- достаточная линейная сложность (для криптографического применения).

Эти свойства обычно проверяют статистическими тестами (например, по критерию $\chi^2$ и корреляционным метрикам).
