# Лабораторная работа № 2
## Гаммирование. Моделирование работы скремблера

## Цель работы
Освоить на практике применение режима однократного гаммирования, исследовать побитное непрерывное шифрование данных и ознакомиться с шифрованием информации при помощи скремблера.

## Вариант и исходные данные
- Вариант: 2.
- Скремблер 1: $x^9 + x^3 + 1$.
- Скремблер 2: $x^9 + x^4 + 1$.
- Язык реализации: Python.
- Графический интерфейс: Tkinter.

## Постановка задания
Требовалось реализовать:
1. Приложение для шифрования.

    - однократное гаммирование (входной текст из файла, случайный ключ, сохранение шифртекста и ключа в отдельные файлы);
    - шифрование каждым скремблером варианта (входной текст и начальное состояние из файлов, сохранение результата в файл);
    - просмотр и изменение данных в двоичном, шестнадцатеричном и символьном представлениях.

2. Приложение для дешифрования.

    - однократное гаммирование (шифртекст и ключ из файлов, сохранение расшифрованного текста);
    - дешифрование каждым скремблером варианта (шифртекст и начальное состояние из файлов, сохранение результата);
    - просмотр и изменение данных в двоичном, шестнадцатеричном и символьном представлениях.

3. Исследование ПСП скремблеров.

    - период;
    - равномерность по критерию $\chi^2$;
    - свойства сбалансированности, цикличности и корреляции.

## Реализация
Приложение реализовано послойно:

- `src/core`: алгоритмы OTP, LFSR-скремблер, преобразования форматов, анализ ПСП;
- `src/ui`: окна Tkinter для шифрования, дешифрования и исследования;
- `src/io_utils.py`: операции чтения/записи файлов.

Использованы соотношения:

- $C_i = P_i \oplus K_i$;
- $P_i = C_i \oplus K_i$;
- $K_i = C_i \oplus P_i$.

Для скремблера гамма генерируется из начального состояния (seed), после чего применяется операция XOR к данным.

## Проверка корректности работы
### Однократное гаммирование (пример)
- Открытый текст (HEX): `48454C4C4F`.
- Ключ (HEX): `0F1E2D3C4B`.
- Шифртекст (HEX): `475B617004`.
- Повторное XOR с тем же ключом возвращает исходный текст: `48454C4C4F`.

### Скремблер (пример)
- Полином: $x^9 + x^3 + 1$.
- Seed: `101001101` (двоичный вид).
- Открытый текст (HEX): `4C6162322076617269616E7432`.
- Шифртекст (HEX): `FEF267A6B85AC5B30C47655D02`.
- Дешифрование с тем же seed восстанавливает исходный текст.

## Исследование ПСП скремблеров
Проверка выполнена для seed = 1, 73, 341.

Скремблер $x^9 + x^3 + 1$:
- период: 21;
- $\chi^2$: от 42.2051 до 785.0703;
- наблюдается выраженная зависимость свойств от начального состояния.

Скремблер $x^9 + x^4 + 1$:
- период: 511;
- $\chi^2$: от 0.0020 до 0.0078;
- равномерность и корреляционные показатели существенно лучше.

## Выполнение аналитических пунктов задания
Если один и тот же ключ ошибочно применён к двум сообщениям, то:

$$
C_1 = P_1 \oplus K,\quad C_2 = P_2 \oplus K,\quad C_1 \oplus C_2 = P_1 \oplus P_2.
$$

Следовательно, при известном $P_1$ второе сообщение восстанавливается без явного поиска ключа:

$$
P_2 = P_1 \oplus C_1 \oplus C_2.
$$

Тестовый пример подтвердил формулу: по $P_1=\texttt{HELLO}$, $C_1$, $C_2$ получено $P_2=\texttt{WORLD}$.

## Вывод
В рамках лабораторной работы реализованы шифрование и дешифрование в режиме однократного гаммирования и с использованием двух скремблеров варианта 2, а также модуль исследования ПСП.  
Практически подтверждены:
- обратимость XOR-преобразования;
- возможность восстановления ключа как $K = P \oplus C$;
- уязвимость повторного использования ключа;
- заметное различие статистических характеристик у двух заданных скремблеров.
