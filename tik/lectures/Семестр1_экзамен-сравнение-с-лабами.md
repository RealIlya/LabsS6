## Вывод

Экзамен 1 семестра был составлен не только по лабораторным работам. По листку видно смешение:

1. **одна задача прямо из лаб/лекций по кодированию**: код Хэмминга;
2. **несколько задач из общего криптографического конспекта**: RSA, Диффи-Хеллман, совершенная/семантическая стойкость;
3. **несколько задач из более современной криптографической теории**: PRG и преобразования PRG;
4. **почти нет прямых задач по lab1, lab2, lab4, lab5**, хотя их темы могут быть базой для понимания.

Главный паттерн: экзамен проверяет не факт выполнения лабораторных, а способность решать короткие криптографические задачи по лекционным понятиям.

## Что это значит для семестра 2

Для подготовки ко 2 семестру нельзя опираться только на `lab1-lab6`. Надо готовить три слоя:

1. **Лабораторные темы**: LFSR, хеши, ANSI X9.17, cryptography, RBAC.
2. **Лекционные задачи**: PRG/PRF/PRP, MAC, хеш-атаки, Merkle-Damgard, RSA/DH.
3. **Базовый общий конспект**: энтропия, кодирование, Хэмминг, модульная арифметика, RSA/DH.

Вероятный формат экзамена 2 семестра: короткий лист на 6-8 заданий, где часть заданий будет по лабам, а часть - по лекционным криптографическим задачам.
