РАЗДЕЛ 2: СИММЕТРИЧНОЕ ШИФРОВАНИЕ
────────────────────────────────────────────────────────────────────────────────

Тест 2.1 — Генерация параметров AES-CBC
Входные данные:
  Вкладка       : Симм. шифрование
  Алгоритм      : AES-CBC
  Действие      : нажать «🔑 Генерировать параметры»
Ожидаемый результат:
  Поля «Ключ (Key, Base64)» и «Вектор (IV, Base64)» заполнены непустыми значениями
  Длина декодированного ключа: 32 байта (256 бит)
  Длина декодированного IV   : 16 байт (128 бит)
  Журнал: "[OK] Параметры для AES-CBC"

────────────────────────────────────────────────────────────────────────────────

Тест 2.2 — Шифрование текста через AES-CBC (ввод в поле)
Входные данные:
  Вкладка            : Симм. шифрование
  Алгоритм           : AES-CBC
  Текст              : "Секретное сообщение"
  Ключ (Base64)      : (сгенерированный на тесте 2.1)
  IV (Base64)        : (сгенерированный на тесте 2.1)
  Входной файл       : не выбран
Ожидаемый результат:
  В окне вывода появляется Base64-строка шифртекста
  Журнал: "[OK] Зашифровано (AES-CBC)"
  Диалог «Сохранить шифртекст в файл?»

────────────────────────────────────────────────────────────────────────────────

Тест 2.3 — Шифрование и дешифрование файла через AES-CFB
Входные данные:
  Вкладка            : Симм. шифрование
  Алгоритм           : AES-CFB
  Действие 1         : Сгенерировать параметры
  Входной файл       : любой файл (например, original.txt)
  Выходной файл      : encrypted.bin
  Действие 2         : Зашифровать
  Затем:
    Входной файл     : encrypted.bin
    Выходной файл    : decrypted.txt
    Действие 3       : Дешифровать
Ожидаемый результат:
  decrypted.txt совпадает с original.txt побайтово
  Журнал: "[OK] Зашифровано (AES-CFB)" и "[OK] Дешифровано (AES-CFB)"

────────────────────────────────────────────────────────────────────────────────

Тест 2.4 — Шифрование DES-CBC
Входные данные:
  Вкладка            : Симм. шифрование
  Алгоритм           : DES-CBC
  Действие           : Сгенерировать параметры
  Ключ (Base64)      : результат генерации (8 байт после декодирования)
  IV (Base64)        : результат генерации (8 байт)
  Текст              : "DES test"
Ожидаемый результат:
  Шифртекст выведен или сохранён
  Длина декодированного ключа: 8 байт
  Журнал: "[OK] Зашифровано (DES-CBC)"

────────────────────────────────────────────────────────────────────────────────

Тест 2.5 — Дешифрование с неверным ключом
Входные данные:
  Вкладка            : Симм. шифрование
  Алгоритм           : AES-CBC
  Входной файл       : файл, зашифрованный с корректным ключом
  Ключ               : другой (случайный) Base64-ключ той же длины
  IV                 : оригинальный
Ожидаемый результат:
  Ошибка в журнале: "[ERR] ..." (ошибка паддинга или неверные данные)
  Диалог с сообщением об ошибке

────────────────────────────────────────────────────────────────────────────────

Тест 2.6 — Генерация параметров 3DES-CBC
Входные данные:
  Вкладка       : Симм. шифрование
  Алгоритм      : 3DES-CBC
  Действие      : Генерировать параметры
Ожидаемый результат:
  Длина декодированного ключа: 24 байта (168 бит)

РАЗДЕЛ 3: АСИММЕТРИЧНОЕ ШИФРОВАНИЕ
────────────────────────────────────────────────────────────────────────────────

Тест 3.1 — Генерация ключевой пары RSA-2048
Входные данные:
  Вкладка       : Асимм. шифрование
  Размер ключа  : 2048
  Действие      : 🔑 Генерировать ключи
  Сохранение    : согласиться, указать пути для priv.pem и pub.pem
Ожидаемый результат:
  Поля «PEM-текст закр. ключа» и «PEM-текст откр. ключа» заполнены
  Оба файла созданы на диске (начинаются с "-----BEGIN RSA PRIVATE KEY-----" и "-----BEGIN PUBLIC KEY-----")
  Журнал: "[OK] Ключевая пара RSA-2048 сгенерирована и вставлена в поля"

────────────────────────────────────────────────────────────────────────────────

Тест 3.2 — Шифрование текста открытым ключом (ввод в поле)
Входные данные:
  Вкладка           : Асимм. шифрование
  Открытый ключ     : PEM-текст из теста 3.1 (в поле) или файл pub.pem
  Текст             : "Конфиденциальные данные"
  Входной файл      : не выбран
Ожидаемый результат:
  JSON-структура {"enc_key":…,"iv":…,"ct":…} выведена в журнал
  Диалог «Сохранить шифртекст в файл?»

────────────────────────────────────────────────────────────────────────────────

Тест 3.3 — Дешифрование JSON-файла закрытым ключом
Входные данные:
  Вкладка           : Асимм. шифрование
  Закрытый ключ     : файл priv.pem из теста 3.1
  Входной файл      : JSON-файл, полученный в тесте 3.2
  Выходной файл     : decrypted.txt
Ожидаемый результат:
  decrypted.txt содержит "Конфиденциальные данные"
  Журнал: "[OK] Дешифровано → decrypted.txt" с текстом в журнале

────────────────────────────────────────────────────────────────────────────────

Тест 3.4 — Дешифрование чужим ключом (негативный)
Входные данные:
  Вкладка           : Асимм. шифрование
  Закрытый ключ     : другой сгенерированный priv.pem (не тот, которым шифровали)
  Входной файл      : JSON-файл из теста 3.2
Ожидаемый результат:
  Диалог с ошибкой (ValueError или аналог)
  Журнал: "[ERR] …"

────────────────────────────────────────────────────────────────────────────────

Тест 3.5 — Генерация ключевой пары RSA-4096
Входные данные:
  Вкладка       : Асимм. шифрование
  Размер ключа  : 4096
  Действие      : Генерировать ключи
Ожидаемый результат:
  Ключи сгенерированы (занимает больше времени, чем RSA-2048)
  PEM закрытого ключа содержит "-----BEGIN RSA PRIVATE KEY-----"
  Длина PEM-блока ключа значительно больше, чем в тесте 3.1

Входные данные:

  Действие      : 🔑 Генерировать ключи RSA-2048
  Пути сохранения: sign_priv.pem, sign_pub.pem
Ожидаемый результат:

Тест 4.2 — Подпись текста (ввод в поле)
Входные данные:
  Вкладка           : Цифровая подпись
  Файл закр. ключа  : sign_priv.pem (из теста 4.1)
  Текст для подписи : "Подписываемое сообщение"
  Файл данных       : не выбран
  Файл подписи      : указать путь для сохранения (sig.json)
  Действие          : ✍ Подписать
Ожидаемый результат:
  Поле «Base64-значение подписи» заполнено (длинная Base64-строка)
  Файл sig.json создан с полями "algorithm" и "signature"
  Журнал: "[OK] Подпись создана (RSA-PSS-SHA256)"

Тест 4.3 — Проверка действительной подписи
Входные данные:

  Файл откр. ключа  : sign_pub.pem (из теста 4.1)
  Текст             : "Подписываемое сообщение" (тот же, что в тесте 4.2)
  Значение подписи  : Base64-строка из поля (из теста 4.2)
  Действие          : ✅ Проверить подпись
Ожидаемый результат:
  Диалог: "✅ Подпись действительна!"
  Журнал: "[OK] ✅ Подпись ДЕЙСТВИТЕЛЬНА"

────────────────────────────────────────────────────────────────────────────────

Тест 4.4 — Проверка подписи при изменённых данных (негативный)
Входные данные:
  Вкладка           : Цифровая подпись
  Файл откр. ключа  : sign_pub.pem
  Текст             : "Подписываемое сообщение ИЗМЕНЁННОЕ"
  Значение подписи  : Base64-строка из теста 4.2 (без изменений)
  Действие          : ✅ Проверить подпись
Ожидаемый результат:
  Диалог: "❌ Подпись недействительна!"

Тест 4.5 — Проверка подписи с чужим открытым ключом (негативный)

  Файл откр. ключа  : другой pub.pem (не пара к sign_priv.pem)
  Текст             : "Подписываемое сообщение"
  Значение подписи  : Base64-строка из теста 4.2
  Действие          : ✅ Проверить подпись

  Диалог: "❌ Подпись недействительна!"
