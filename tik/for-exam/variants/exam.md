## Вариант 1

### Задача 5

**Правильный ответ:** **3**

#### Решение

В двухраундовой сети Фейстеля сбалансированного типа уравнения раундов выглядят следующим образом:

1. $R_1 = L_0 \oplus F(k_1, R_0)$, $L_1 = R_0$
2. $R_2 = L_1 \oplus F(k_2, R_1) = R_0 \oplus F(k_2, R_1)$, а половина $L_2 = R_1 = L_0 \oplus F(k_1, R_0)$

Выходное значение представляется парой половин. Проследим за изменением $L_2$ (которая равна $R_1$) для двух заданных входов:

* Для входа $0^{64}$: $L_0 = 0^{32}$, $R_0 = 0^{32}$. Тогда $L_2^{(1)} = 0 \oplus F(k_1, 0) = F(k_1, 0)$.
* Для входа $1^{32}0^{32}$: $L_0 = 1^{32}$, $R_0 = 0^{32}$. Тогда $L_2^{(2)} = 1^{32} \oplus F(k_1, 0)$.

Заметим, что значение $L_2^{(2)}$ для второго входа является точной побитовой инверсией (XOR с $1^{32}$) значения $L_2^{(1)}$ для первого входа.

Посмотрим на **Вариант 3**:

* Выход для $0^{64}$: `"290b6e3a 39155d6f"`
* Выход для $1^{32}0^{32}$: `"d6f491c5 b645c008"`

Проверим побитовую инверсию первых половин (`290b6e3a` и `d6f491c5`):

```text
290b6e3a XOR ffffffff = d6f491c5

```

Половины идеально инвертируют друг друга, что однозначно выдает структуру сети Фейстеля и доказывает, что эта строка получена не из истинно случайной перестановки.

## Вариант 2

### Задача 1

**Правильный ответ:**

* [x] $2$

#### Решение

В режиме CBC (Cipher Block Chaining) формула расшифрования блока имеет вид:


$$m_i = D_k(c_i) \oplus c_{i-1}$$

Если блок шифротекста $c_{L/2}$ поврежден, то:

1. При расшифровании блока $m_{L/2}$ значение $D_k(c_{L/2})$ полностью исказится из-за лавинного эффекта блочного шифра $\implies$ **1-й поврежденный блок**.
2. При расшифровании блока $m_{L/2+1}$ формула примет вид $D_k(c_{L/2+1}) \oplus c_{L/2}$. Ошибки из $c_{L/2}$ напрямую перенесутся через XOR в открытый текст $\implies$ **2-й поврежденный блок**.

На остальные блоки этот дефект не повлияет. Пострадают ровно **2** блока.

### Задача 2

* [x] 'In this letter I make some remarks on a general principle relevant to enciphering in general and my machine.'

#### Решение

Размер блока AES составляет 16 байт. В режиме CBC со случайным IV полный размер перехваченного пакета (128 байт) состоит из IV (16 байт) и блоков шифротекста.
Следовательно, на зашифрованные блоки данных приходится $128 - 16 = 112$ байт. Из-за дополнения PKCS#7 длина исходного сообщения в байтах (символах) должна строго попадать в диапазон:


$$\text{От } (112 - 16) = 96 \text{ до } (112 - 1) = 111 \text{ байт}$$

Подсчитаем длины строк-кандидатов:

* Строка 1: 165 символов
* Строка 2: 124 символа
* **Строка 3: 108 символов** (удовлетворяет условию)

### Задача 3

**Правильный ответ:** **17**

#### Решение

Дано: $N = 35$, $e = 7$, $c = 3$. Необходимо найти $m$, такое что $m^7 \equiv 3 \pmod{35}$.

1. Разложим модуль: $N = 5 \times 7$.
2. Функция Эйлера: $\phi(35) = (5-1)(7-1) = 24$.
3. Наведя мультипликативно обратное для $e$: $7 \cdot d \equiv 1 \pmod{24} \implies d = 7$ (так как $7 \times 7 = 49 \equiv 1 \pmod{24}$).
4. Расшифруем: $m = c^d \pmod N = 3^7 \pmod{35}$.

Вычислим $3^7 \pmod{35}$:

* $3^3 = 27$
* $3^4 = 81 \equiv 11 \pmod{35}$
* $3^7 = 3^3 \times 3^4 = 27 \times 11 = 297 \equiv 17 \pmod{35}$

Исходное сообщение $m = 17$.

### Задача 4

**Правильный ответ:**

* [x] Выбираем $x1, y1, y2$ произвольно ($y1 \neq y2$) и полагаем $v:=AES(y1, x1)$, $x2:=AES^{-1}(y2, v \oplus y1 \oplus y2)$

#### Решение

Функция сжатия: $f1(x,y) = \text{Enc}_y(x) \oplus y$.
Для первой пары: $f1(x1, y1) = \text{Enc}_{y1}(x1) \oplus y1 = v \oplus y1$.
Для предложенного варианта найдем $x2$:


$$x2 = \text{Dec}_{y2}(v \oplus y1 \oplus y2) \implies \text{Enc}_{y2}(x2) = v \oplus y1 \oplus y2$$

Подставим во вторую функцию сжатия:


$$f1(x2, y2) = \text{Enc}_{y2}(x2) \oplus y2 = (v \oplus y1 \oplus y2) \oplus y2 = v \oplus y1$$


Значения совпали ($f1(x1, y1) = f1(x2, y2)$), коллизия успешно найдена.

* *Аргументация:* Последний бит сообщения полностью игнорируется. Сообщения, отличающиеся только последним битом, имеют одинаковый тег, что позволяет мгновенно совершить подделку.

#### Решение

В режиме счетчика CTR схема расшифрования имеет вид:

Поскольку искажение блока шифротекста $c_{L/2}$ участвует только в операции XOR для восстановления блока $m_{L/2}$ и никак не влияет на генерацию гаммы шифра для соседних блоков, ошибка не распространяется. Будет поврежден строго **1** блок.

### Задача 2

**Правильный ответ:**

* [x] Тег $(r \oplus 1^n, t)$ – валидный для 1-блочного сообщения $m \oplus 1^n$

#### Решение

Для исходного сообщения $m$ тег равен $t = \text{ECBC}_k(r, m)$, где на первом этапе вычисляется значение $\text{Enc}_{k1}(m \oplus r)$.
Посмотрим, что произойдет при верификации поддельного сообщения $m' = m \oplus 1^n$ с новым вектором инициализации $r' = r \oplus 1^n$:


$$m' \oplus r' = (m \oplus 1^n) \oplus (r \oplus 1^n) = m \oplus r \oplus 1^n \oplus 1^n = m \oplus r$$


Так как входной блок для первого раунда шифрования совпал с оригинальным, итоговый тег также полностью совпадет и будет равен $t$.

* [x] $H'(m) = H(m) \parallel H(m)$

### Задача 5

**Правильный ответ:**

* [x] $c1 = c0'$

#### Решение

Разберем первый запрос для сообщения $m = (0^\ell, 0^\ell)$ с $\text{nonce} = 0^\ell$:

1. Вектор инициализации: $\text{IV}_1 = F(\text{key}, 0^\ell)$.
2. Первый блок шифротекста: $c_0 = F(\text{key}, 0^\ell \oplus \text{IV}_1) = F(\text{key}, \text{IV}_1)$.
3. Второй блок шифротекста: $c_1 = F(\text{key}, 0^\ell \oplus c_0) = F(\text{key}, c_0)$.

Разберем второй запрос для сообщения $m_1' = c_0 \oplus c_1$ с $\text{nonce}' = c_0$:

1. Вектор инициализации: $\text{IV}_2 = F(\text{key}, \text{nonce}') = F(\text{key}, c_0)$. Из уравнения для $c_1$ мы видим, что $F(\text{key}, c_0) = c_1$. Следовательно, $\text{IV}_2 = c_1$.
2. Вычисляем блок шифротекста $c_0'$:

$$c_0' = F(\text{key}, m_1' \oplus \text{IV}_2) = F(\text{key}, (c_0 \oplus c_1) \oplus c_1) = F(\text{key}, c_0)$$



Снова подставляя значение $F(\text{key}, c_0) = c_1$, получаем искомое соотношение:


$$c_0' = c_1$$
