## Блок 1

### Задача 5 (Определение 2-раундовой сети Фейстеля)

**Решение:**
Двухраундовая сеть Фейстеля не является псевдослучайной перестановкой (PRP), так как она не обеспечивает полную диффузию. Это позволяет построить различитель (distinguisher).

1.  **Анализ схемы:**
    Пусть входной 64-битный блок делится на две 32-битные половины: левую $L_0$ и правую $R_0$. (На схеме $R_0$ сверху, $L_0$ снизу, но логика перекрестий стандартная).
    Опишем преобразования по раундам:
    - **Раунд 1:**
      $L_1 = R_0$
      $R_1 = L_0 \oplus F(k_1, R_0)$
    - **Раунд 2:**
      $L_2 = R_1 = L_0 \oplus F(k_1, R_0)$
      $R_2 = L_1 \oplus F(k_2, R_1) = R_0 \oplus F(k_2, R_1)$
      Выход сети состоит из половин $L_2$ и $R_2$ (обычно конкатенируются как $L_2 \parallel R_2$).

2.  **Применение заданных входов:**
    Нам даны два входа:
    - Вход A: $0^{64}$. То есть $L_{0A} = 0^{32}$, $R_{0A} = 0^{32}$.
    - Вход B: $1^{32}0^{32}$. То есть $L_{0B} = 1^{32}$ (все единицы), $R_{0B} = 0^{32}$.

    Заметим ключевую особенность: **правые половины обоих входов равны** ($R_{0A} = R_{0B} = 0^{32}$).

3.  **Поиск коллизии/закономерности:**
    Посмотрим, что произойдет с половиной $L_2$ для обоих входов:
    - Для входа A: $L_{2A} = L_{0A} \oplus F(k_1, R_{0A}) = 0^{32} \oplus F(k_1, 0^{32}) = F(k_1, 0^{32})$
    - Для входа B: $L_{2B} = L_{0B} \oplus F(k_1, R_{0B}) = 1^{32} \oplus F(k_1, 0^{32})$

    Сложим их по модулю 2 (операция XOR, $\oplus$):
    $L_{2A} \oplus L_{2B} = F(k_1, 0^{32}) \oplus 1^{32} \oplus F(k_1, 0^{32}) = \mathbf{1^{32}}$

    **Вывод:** Если выходы сгенерированы этой 2-раундовой сетью Фейстеля, то одна из 32-битных половин (левая или правая, в зависимости от порядка конкатенации) у двух шифротекстов при операции XOR должна дать $1^{32}$.
    В шестнадцатеричном виде $1^{32}$ — это строка из восьми букв `f` (`ffffffff`).
    Истинная случайная перестановка даст такой результат с пренебрежимо малой вероятностью ($1/2^{32}$).

4.  **Проверка вариантов ответа:**
    Ищем вариант, где одна из половин первого выхода при XOR со второй половиной дает `ffffffff`. (В 16-ричной системе $x \oplus y = f \implies$ биты полностью инвертированы).
    - **Вариант 1:**
      Половина 1: `7b50baab` $\oplus$ `ac343a22` $\neq$ `ffffffff` (т.к. 7 $\oplus$ a = d)
    - **Вариант 2:**
      Половина 1: `5f67abaf` $\oplus$ `bbe033c0` $\neq$ `ffffffff` (т.к. 5 $\oplus$ b = e)
    - **Вариант 3:**
      Половина 1: `290b6e3a` $\oplus$ `d6f491c5`.
      Проверим посимвольно:
      2 $\oplus$ d = 0010 $\oplus$ 1101 = 1111 (f)
      9 $\oplus$ 6 = 1001 $\oplus$ 0110 = 1111 (f)
      0 $\oplus$ f = 0000 $\oplus$ 1111 = 1111 (f)
      b $\oplus$ 4 = 1011 $\oplus$ 0100 = 1111 (f)
      6 $\oplus$ 9 = 0110 $\oplus$ 1001 = 1111 (f)
      e $\oplus$ 1 = 1110 $\oplus$ 0001 = 1111 (f)
      3 $\oplus$ c = 0011 $\oplus$ 1100 = 1111 (f)
      a $\oplus$ 5 = 1010 $\oplus$ 0101 = 1111 (f)
      **Результат: `ffffffff`. Идеальное совпадение.**

    - **Вариант 4** (для убедительности):
      Половина 1: `9d1a4f78` $\oplus$ `75e5e3ea` $\neq$ `ffffffff` (т.к. 9 $\oplus$ 7 = e)

**Ответ: 3** (Строки из 3-го варианта являются выходом данной сети Фейстеля, так как XOR их первых 32-битных блоков равен `ffffffff`, что доказывает структурную уязвимость 2-х раундов).
