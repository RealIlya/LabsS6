### Задача 1

**Решение:**
В режиме счетчика (CTR) шифрование и расшифрование идет наложением гаммы (XOR):
Шифрование: $C_i = P_i \oplus E_K(CTR_i)$
Расшифрование: $P_i = C_i \oplus E_K(CTR_i)$

Генерация гаммы $E_K(CTR_i)$ зависит **только** от ключа и значения счетчика. Она никак не зависит от предыдущих или текущих блоков шифротекста $C$.
Т.к. ошибка (искажение битов) произошла только в блоке $C_{L/2}$, то при операции $P_{L/2} = C_{L/2} \oplus E_K(CTR_{L/2})$ испортится только один этот блок открытого текста. Остальная гамма сгенерируется корректно.

**Ответ: 1**

### Задача 2

**Решение:**
Из условия мы знаем, как алгоритм вычисляет тэг. Злоумышленник сделал запрос для сообщения $m$ со случайным $IV = r$ и получил тэг $t$.
Формула тэга: $t = E_K(m \oplus r)$.

Чтобы совершить подделку (forgery), нам нужно сгенерировать такой новый вектор $IV'$ и новое сообщение $m'$, чтобы при вычислении $E_K(m' \oplus IV')$ под шифрование попало то же самое значение, что и в первый раз (тогда мы сможем использовать старый тэг $t$).
То есть нам нужно, чтобы выполнялось равенство:
$m' \oplus IV' = m \oplus r$

Проверим **четвертый** вариант ответа из списка:
Предлагается тэг **$(r \oplus 1^n, t)$** для нового сообщения **$m \oplus 1^n$**.
Здесь:
Новый вектор $IV' = r \oplus 1^n$
Новое сообщение $m' = m \oplus 1^n$

Подставим их в проверку алгоритма верификации:
$m' \oplus IV' = (m \oplus 1^n) \oplus (r \oplus 1^n)$

Так как операция XOR ассоциативна и коммутативна, перегруппируем:
$= m \oplus r \oplus (1^n \oplus 1^n)$

Одинаковые значения при сложении по модулю 2 дают ноль ($1^n \oplus 1^n = 0^n$):
$= m \oplus r \oplus 0^n = m \oplus r$

Получается, что для этого нового сообщения и нового вектора $IV$ алгоритм будет вычислять $E_K(m \oplus r)$. Но мы уже знаем из первого перехвата, что $E_K(m \oplus r) = t$.
Значит, старый тэг $t$ идеально подойдет! Подделка успешна.

_(Для справки, вариант 3 с `(m ⊕ t, t)` дал бы $E_K(0^n \oplus m \oplus t) = E_K(m \oplus t) \neq t$, поэтому он неверен)._

**Ответ:** Выбираем вариант **- Тег $(r \oplus 1^n, t)$ – валидный для 1-блочного сообщения $m \oplus 1^n$**

### Задача 3

**Решение:**
RSA: $N=33, e=3, c=3$. Найти $m = c^d \pmod N$.

1. Факторизация $N$: $N = 33 = 3 \times 11 \implies p=3, q=11$.
2. Функция Эйлера: $\phi(N) = (p-1)(q-1) = 2 \times 10 = 20$.
3. Поиск секретной экспоненты $d$:
   $e \cdot d \equiv 1 \pmod{\phi(N)}$
   $3 \cdot d \equiv 1 \pmod{20}$
   $3 \cdot 7 = 21 \equiv 1 \pmod{20} \implies d = 7$.
4. Расшифрование:
   $m = 3^7 \pmod{33}$
   Считаем:
   $3^3 = 27 \equiv -6 \pmod{33}$
   $3^6 = (-6)^2 = 36 \equiv 3 \pmod{33}$
   $3^7 = 3^6 \cdot 3 \equiv 3 \cdot 3 = 9 \pmod{33}$

**Ответ: m = 9**

### Задача 4

**Решение:**
Проверяем свойства $H'$ при условии, что $H$ криптографически стойкая (CRHF):

1. $H'(m) = H(m) \oplus H(m \oplus 1^{|m|})$ — **Нет**. Коллизия тривиальна: $H'(x) = H'(\bar{x})$ в силу коммутативности XOR.
2. $H'(m) = H(m)[0\dots31]$ — **Нет**. Выход всего 32 бита. По парадоксу дней рождений коллизия ищется за $\approx 2^{16}$ операций (небезопасно).
3. $H'(m) = H(H(m))$ — **Да, устойчива**.
   _Доказательство от противного:_ пусть нашли $m_1 \neq m_2$, что $H(H(m_1)) = H(H(m_2))$.
   Это значит, либо $H(m_1) = H(m_2)$ (нашли коллизию для $H$, противоречие), либо $X = H(m_1), Y = H(m_2)$ и $H(X) = H(Y)$ при $X \neq Y$ (снова нашли коллизию для $H$, противоречие).
4. $H'(m) = H(m) \oplus H(m)$ — **Нет**. Всегда выдает 0. $H'(x) = H'(y) = 0$.
5. $H'(m) = H(0)$ — **Нет**. Константа, коллизии для любых $x, y$.
6. $H'(m) = H(m) \parallel H(m)$ — **Да, устойчива**. Если конкатенации равны, то равны и части $\implies H(x)=H(y) \implies$ сводится к стойкости $H$.

**Ответ:** Основная устойчивая функция: **$H'(m) = H(H(m))$**. _(Также формально подходит $H'(m) = H(m) \parallel H(m)$)_.

### Задача 5

**Решение:**
Схема CBC: $IV = E_K(nonce), C_i = E_K(m_i \oplus C_{i-1})$. Обозначим $E_K$ как $E$.

**Запрос 1:** $m = (0^\ell, 0^\ell)$, $nonce = 0^\ell$.
$IV_1 = E(0^\ell)$
$c_0 = E(m_0 \oplus IV_1) = E(0^\ell \oplus E(0^\ell)) = E(E(0^\ell))$
$c_1 = E(m_1 \oplus c_0) = E(0^\ell \oplus c_0) = E(c_0)$
_Вывод (подсказка):_ **$c_1 = E(c_0)$**

**Запрос 2:** $m_1 = c_0 \oplus c_1$, $nonce = c_0$.
Новый $IV_2 = E(nonce) = E(c_0)$.
Т.к. из первого запроса мы знаем, что $E(c_0) = c_1$, след-но: **$IV_2 = c_1$**.
Вычисляем шифротекст:
$c_0' = E(m_1 \oplus IV_2)$
Подставляем $m_1$ и $IV_2$:
$c_0' = E((c_0 \oplus c_1) \oplus c_1) = E(c_0 \oplus 0^\ell) = E(c_0)$
Снова используем вывод из первого запроса ($E(c_0) = c_1$):
**$c_0' = c_1$**

**Ответ:** Выбираем вариант **$c_1 = c_0'$**
