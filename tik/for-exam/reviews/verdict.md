Важное замечание: старый DOCX не стоит считать эталонными решениями. Там есть как минимум подозрительное место: в задаче про **encrypted CBC-MAC** выбран ответ `n`, но если известен ключ MAC и есть тег, для ECBC-MAC естественный пересчёт последнего изменённого блока делается через несколько AES-вызовов, а не через полный пересчёт всего сообщения. То есть файл полезен как источник типов задач, но ответы надо перепроверять.

Мой вывод для подготовки: старые КР очень полезны для **MAC / PRF / hash / block cipher modes**, но они **не заменяют** файл [Семестр2*Задачи*из_лекций-исправленные.md](for-exam/tasks/Семестр2_Задачи_из_лекций-исправленные.md:1). Для экзамена я бы готовил их как дополнительный блок после лекционных задач 3, 5, 6, а первую половину курса по информации и кодированию всё равно учить по нашему файлу решений.
